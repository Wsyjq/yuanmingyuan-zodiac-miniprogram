0. 这份材料先回答什么

西洋楼在长春园北部自成一区，今天游客几乎只记得大水法残迹。写任何一句解说之前，先卡住三件事：

  1. 铜版画是伊兰泰起稿、造办处在北京刻的 20 幅，没有第二十一幅；「送法国刻版」是另一套图（《平定西域战图》）的故事。
  2. 谐奇趣竣工取乾隆十六年（1751）秋，不是 1747；1747 是筹划 / 试作喷泉之年。
  3. 香妃寝宫、现迷宫是乾隆原墙、郎世宁一个人设计西洋楼——这三类句子不要当史实输出。

下文按「硬裁决 → 年表 → 二十幅 → 分建筑 → 水法 → 图像考古回归 → 机构论文 → 分站用法 → 安全句 → 仍缺」排列。链接以公开网页为准；官网 yuanmingyuanpark.cn 部分栏目需在国内网络打开。

3. 铜版画二十幅

定名：故宫正式名《圆明园长春园图》/《圆明园铜版画》册。亦可称《西洋楼透视图铜版画》。产品若用「第二十一图」，必须标成 🟧——档案无第 21 幅。

制作（活计档，翁连溪辑；34 期） 🟦

  • 乾隆四十六年四月二十八日：太监鄂勒里传旨「伊兰泰现起谐奇趣图稿不能即时落墨，着向造办处要两人进内落墨」。
  • 乾隆四十七年二月十三日：如意馆画得西洋楼水法图画第一至六张，旨「交舒文刻做铜板」。
  • 约估：铜板 20 块；34 期记每版红铜约 25 公斤、开幅长 93 厘米、高 57 厘米。活计档另有红铜共约 1044 斤、工价银约 4235.7 两（减工后）的算法。
  • 印制共 200 份（首版 100 + 加印 100），用于赏赐并陈设紫禁城、三山五园及各行宫。长春园含经堂原贮一套（官网含经堂页）。
  • 乾隆五十一年（1786）成。中国工匠在京雕版，不是送法国。
  • 绘制者：伊兰泰、贺清泰、潘廷璋等如意馆画师（34 期名单比故宫讲座更全）。

纸图尺寸：故宫古籍页 50.7×88 cm；藏品页 / 鸿禧 50.5×87.5 cm。

存世印本：故宫（故 00009171）、国图、北大图书馆、沈阳故宫、巴黎国家图书馆、曼彻斯特大学约翰·赖兰兹图书馆。1977 年巴黎 Jardin de Flore 据法图 1:1 复刻。铜版 1860 年被掠、推测藏于法国——此为故宫讲座转述，对外须加「据故宫讲座」。

4. 分建筑（西→东）

官网 12 个景点页已全部直接抓取（/cgll/zyjd/ccy/201101/t20110105_231500–231511.html）。下列要点以官网原文为准，冲突处见 §1。

4.1 谐奇趣 + 其蓄水楼

  • 🟦 官网：「乾隆十六年（1751）秋季竣工，是西洋楼景区第一座欧式建筑。主楼三层，是演奏中西音乐之处。」
  • 🟦 南池：铜燕、铜羊、西洋翻尾石鱼；北池菊花式。罹难后翻尾石鱼流散北京大学；菊花池曾在东城翠花胡同，1987 年原址复位。
  • 🟨 南池动物三说：官网景点页铜燕 + 铜羊；鸿禧铜羊 + 铜鸭；官网御制诗 PDF「铜鹅、铜鸭」。不揉成一句。
  • 🟦 西北蓄水楼供水。这是谐奇趣的蓄水楼，不要和海晏堂工字蓄水楼混成一座。
  • 🟦 郭黛姮：库房琉璃残片能对上奥尔末照片的女儿墙 / 腰线 / 墙饰 → 「五彩」，不是纯白石巴洛克。光明日报 2020-11-07
  • 🟦 北大文物页：谐奇趣翻尾石鱼今在未名湖西侧；口喷水柱可升十余米（盛期记载）。北大页

4.2 黄花阵 / 万花阵

  • 🟦 官网：谐奇趣北面；仿欧洲迷宫；阵墙总长 1600 余延长米，墙高约 1.2 米，镶卍字雕花青砖；中心高台圆基八方西式亭。
  • 🟦 1987、1989 先后在原址按原样修复全部阵墙和欧式圆亭。
  • 🟧 中秋宫女提黄绸莲花灯赛跑——写在官网介绍里，未见活计档直接出处。可用「据说」，不要写成档案。
  • 🟨 65 期：用砖砌矮墙代替欧洲绿篱；「九个大小不同的正圆」。

4.3 养雀笼

  • 🟦 官网：谐奇趣之东，通往东部西洋各景的入口；西中式牌楼、东西洋宫门；约 1759。南北室内笼孔雀。现状：西面牌楼基座 + 东面部分石件。
  • 🟦 45 期 / 84 期：常年笼养各种鸟类 400 多只 / 四百多只。
  • 🟦 83 期：已发掘。

4.4 方外观 + 五竹亭

  • 🟦 官网：养雀笼之东，1759，二层西式小楼，左右环形石阶。竹亭在其对面。
  • 🟨 / 官方叙事：官网原文写成容妃（香妃）做礼拜的清真寺，并引两石碑阿拉伯文（云已不存、碑文被复制）。故宫容妃页同。
  • 🟦《清史稿·后妃传》只有「又有容妃，和卓氏，回部台吉和卓赉女。初入宫，号贵人。累进为妃。薨。」无方外观、无清真寺、无香妃封号。
  • 对外：中西立面最适合讲「哪些是欧洲的、哪些被改了」。若提礼拜，必须说「这是公园介绍和故宫人物页的写法，正史没有记到这一句」。

4.5 海晏堂 + 工字蓄水楼

  • 🟦 官网：西洋楼景区最大景观；乾隆二十四年（1759）基本建成；正楼朝西；十二生肖人身兽首水力钟；楼后工字形平台供水楼，中段蓄水池俗称「锡海」，一次可蓄水 160 余立方米。
  • 🟦 故宫词条：南列子鼠寅虎辰龙午马申猴戌狗，北列丑牛卯兔巳蛇未羊酉鸡亥猪；兽首铜质、人身石质、中空接水管。锡海「可盛水 180 吨」。
  • 🟦 郭黛姮：地下铜水管探地雷达探测，近 300 年仍完好。
  • 🟦 2016 年蓄水楼本体加固（官网新闻：2016-04-22 开工，约 2 个月，16 万块地趴砖）。
  • 现场游客看到的高夯土台，是海晏堂后工字楼，不是谐奇趣西北那座蓄水楼。
  • 兽首不要写成「最值钱」。切口可以是：「它首先是一座用水做成的钟。」

4.6 大水法 · 观水法 · 远瀛观

御制诗释文 🟦（研究报告 PDF，形制最完整）：

海晏堂迤东为远瀛观，居长春园南北主线与西洋楼东西轴线交会处。大水法与观水法为乾隆二十四年建成，北侧南向主殿则为四十八年（1783）增建。……水法主建筑为巨型石龛式，前有狮子头喷水瀑布……落入菊花式喷水池，池中心有只铜鹿，从鹿角喷出八道水柱，两侧散布十只铜狗及卷尾铜兽……左右前方各有一座十三级西式喷水塔，塔周围还各有四十四根铜管一齐喷水。

  • 🟦 大水法页：喷泉全开「有如山洪暴发，声传数里」，皇帝与大臣交谈需打手势。铜鹿 + 十铜狗 1860 后无回归，现场只剩石座。
  • 🟦 观水法页：坐南朝北平台，宝座后五件石雕屏风；1977 运回原址归位。1793 英使、1795 荷兰使曾来此观看。
  • 🟦 远瀛观页：乾隆四十八年（1783）添建；倒凹字形 17 间；汉白玉巨柱刻下垂葡萄花纹。1793 年起陈设英王赠天体运行仪。
  • 🟦 泽兰堂：长春园中轴北山阳坡，乾隆书房，居高观览西洋楼和大水法。乾隆六十年诗自注：乾隆十八年葡萄牙使来，命郎世宁造水法给来使看——「初不以为贵也」。
  • 🟧 远瀛观 = 香妃寝宫。不用。

4.7 线法山 · 方河 · 线法画

  • 🟦 线法山页：「线法即西洋焦点透视法之意」；圆形土山高约 8 米；俗称转马台；东门螺蛳牌楼。1933 年地方当局曾在山上建哨所看守遗物。
  • 🟦 线法画页：方河东岸七道八字断墙，墙面悬西洋风景画，自西岸望之成透视街市。线法墙今已荡然无存。
  • 🟨 86 期：样式雷上两列 11 面梯形收口，强化一点透视。
  • 🟨 91 期（农大）：线法山样式雷图档中间水池有水线，曾利用西洋水法机械成喷泉。

4.8 含经堂（中式，但和铜版画有关）

  • 🟦 官网：堂内原贮乾隆《钦定重刻淳化阁帖》和《西洋楼铜版图》各一套——铜版画园内陈设位的直接证据。

  • 能说：铜版画正面可对残柱；墙面曾有《古兰经》文 / 阿拉伯碑文的记载；最适合问「哪些是欧洲的、哪些被改了」。
  • 不要说：香妃清真寺、体有异香。若提容妃礼拜，必须标明这是公园介绍 / 故宫人物页的写法，正史不载。
  • 养雀笼可作一句铺垫：「西边中式牌楼，东边西洋门。」

海晏堂（时间）

  • 能说：1759；十二生肖按十二时辰喷水，正午齐喷；兽首是计时装置的出水口；锡海一次可蓄一百六十余立方米；2015–2016 考古与加固。
  • 不要说：兽首「最值钱」；五个下落不明兽首的拍卖传奇当史实；和「大水法」混名。

蓄水楼（水从哪来）

  • 能说：工字蓄水楼、水车房；铜版画「蓄水楼东面」窗内可见机械；高台蓄水 + 势能喷出。
  • 不要说：某一种动力装置是唯一答案；谐奇趣蓄水楼和海晏堂蓄水楼是同一座。

大水法 · 观水法 · 远瀛观（缺席）

  • 能说：石龛、十三级喷水塔、猎狗逐鹿石座仍在；铜鹿铜狗已失；1873 年奥尔末拍照时石龛上还嵌着琉璃；观水法石屏 1977 回归；远瀛观主殿比谐奇趣晚三十多年。
  • 不要说：香妃寝宫；把残迹说成完整巴洛克教堂；陆伟猎狗逐鹿复原图不加「推想图」。

线法山 · 方河 · 线法画（尾声）

  • 能说：「线法」= 透视法；七道断墙挂画，西望成街市；墙今已不存。
  • 深讲可接 86 期 11 面研究结论、91 期水线，均须点名论文。
