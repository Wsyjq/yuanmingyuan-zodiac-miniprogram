## 玩法说明（照此实现；2026-09-11 补）

一册实体档案＋小程序。玩家沿西洋楼从西往东走六个主线点位，每到一站翻到档案对应页，做「纸和地」的对读；过了发日期卡，最后拼图、出报告。

**全局规则**

- 校验哲学：能自校验的全部自校验——对上就是对上，不拍照、不提交、不判分；开放题永不裁判。
- 日期卡：每过一道对读发一张，各印一位数字；八张连起来＝建档日 `YYYYMMDD`（例 20260910）。
- 支线六处全部可选：不出日期卡、不出必需残片；跳过任何或全部，结局照常成立。
- 反结算：无步数、无用时、无完成率、无排行。
- 提示只在卡住时出现。

**小程序与实体的分工（所有对读通用）**

- 实体负责材料与判定：纸、卡、转盘都在道具包里，"对上就是对上"全靠实物自校验。
- 小程序只做四件事：到站出一句生疑、卡住才出提示、过关发日期卡＋点亮地图、收开放题不判。

**主线各位置对读的具体玩法**

**① 入口 · 半字**（对纸和纸）
- 位置：西洋楼入口。手里：实体信封（正面铜版画图样；封口印着三个字的下半截）＋信纸一张（**正面印信全文，背面印那三个字的上半截**）。
- 玩法：撕开封口抽信读 → 信读完回头，看见封口上留着半截字（下面一半）→ 信纸翻到背面，印着上面那一半 → 两半上下拼合。
- 判定：拼出「黄花阵」即过，不拍照不提交；卡住才出两条提示。
- 产出：无卡；小程序点亮黄花阵。

**② 黄花阵 · 对读一 灯戏图对空墙**（阵前）
- 位置：迷宫入口，进阵前。手里：夹照片那页的正面「灯戏图」（夜景，人提灯往中心亭跑）。现场：白天的阵墙与通道。
- 玩法：先对墙——画上墙的走向和眼前对得上；再对人——画上有人、地上没有。小程序问一句「他们在干什么？」，文字或语音作答。
- 判定：开放作答，命中「中秋／灯／宫女／玩／赏」任一即过；可跳过（跳过不发该卡）。
- 产出：年卡1（数字 2）＋揭晓（中秋灯会）。

**③ 黄花阵 · 对读二 黄花从哪来**（同页第二拍）
- 位置：原地。手里：同一页，看画中细节——灯的颜色与样式。
- 玩法：小程序追问「这地方叫黄花阵，黄花是不是从灯上来的？」→ 看画：黄绸扎的莲花灯。
- 判定：开放作答，「黄绸／莲花灯／灯」即过；可跳。
- 产出：年卡2（0）。

**④ 黄花阵 · 走**（阵内，非对读）
- 手里：俯视连线卡（印墙、不印路）。玩法：自己选路走，走错退回；人站到中心亭即完成。无判定、无卡；走到亭下才解锁对读三。

**⑤ 黄花阵 · 对读三 亭子线稿对眼前亭**（亭下）
- 位置：中心八角亭下。手里：档案另一页亭子线稿。现场：抬头看亭。
- 玩法：举线稿对照，先自己找「哪里对得上、哪里对不上」；用手机拍下中西混作的细节——找到一处即算（穹顶vs飞檐／檐角立饰／莲座+宝瓶／双天鹅里藏蝙蝠，卡住才出这四条细目）。
- 判定：观察＋拍照，产品不判图；拍完点「记下了」。
- 产出：年卡3（2）＋**正页残片·一**（亭与墙）。

**⑥ 黄花阵 · 对读四 纹样页举纸对照**（出亭沿墙）
- 位置：出亭沿墙走。手里：纹样页（四种纹样图样）。现场：这一路看到的墙纹。
- 玩法：纸举到墙跟前一处一处比（别贴墙），对上的那张就是万字纹（另三种墙上没有）；小程序点「我认出了」。
- 判定：举纸对上即自校验；可跳。
- 产出：年卡4（6）。
- 收尾（非对读）：翻照片背面「照原图，复位。1987、1989」＋离墙看砖——纯叙述；全程不可跳的只有这两下。

**⑦ 海晏堂 · 对读一 喷泉页对干池**（殿前）
- 位置：扇形干池边。手里：喷泉页（十二兽首齐喷铜版画）。现场：干池＋残座。
- 玩法：先对照画与池（画上喷、地上干）；小程序出三格：鼠（子）→牛（丑）→？并问「十二尊齐喷是什么时辰」。
- 判定：答「寅（虎）」「午」即过——全程唯一纯推理题；可跳。
- 产出：月卡1（0）。盛况呈现＝静态铜版画翻页，不用视频（制作备忘 2）。

**⑧ 海晏堂 · 对读二 转盘对座纹**（座旁）
- 位置：兽首座基旁。手里：花纹转盘（七种纹）。现场：座身残存纹样。
- 玩法：现场认纹（棕叶／茛苕／贝壳／番花／卷草／莲花／海水江岸）→ 转盘转到对应纹对齐 → 镂空显出兽首符号与序号 → 按序号读出回归七尊（牛虎猴猪鼠兔马）。
- 判定：转盘对齐即读出，自校验；可跳。
- 产出：月卡2（9）。

**⑨ 海晏堂 · 对读三 水显纸对正午那尊**（收尾）
- 手里：水显纸一张＋道具包内清水或湿纸巾。
- 玩法：蘸水涂纸 → 显出马首轮廓 → 对上「正午值班的那尊就是马」。
- 判定：显影自校验（园方若禁滴水，改湿纸巾）；可跳。
- 产出：日卡1（1）＋**正页残片·二**（水力钟）。

**⑩ 大水法**（零对读）
- 到站一句 → 两分钟完全静默（可跳）→ 三选一「你听见的是什么」（可跳，本站唯一手机操作）→ 之后无音频。无道具、无卡、无残片。

**⑪ 雨果 · 对读 座上的年对信封的年**（像前）
- 位置：雕像底座前。手里：封套里拆出的信＋几张乱序年份条子。现场：底座刻的年份。
- 玩法：发现底座的年与信封的年对不齐 → 小程序时间轴，把 1747 始建／1760 核心成／1860 火烧／1861 信／2010 像拖回原位 → 全对即过（可跳，跳过直接读信）。
- 产出：日卡2（0，八张到齐）＋**正页残片·三**（信的轮廓）。
- 后续非对读：那封信自己抽出来读，读完即过；四件东西卡自排一列不评分；开放问不给选项不投票；明信片想写就写、可投信箱（下一位在本站读到一张）或带走。

## 序章

你对圆明园的西洋楼有兴趣，不然不会读到这里。这套铜版画一共二十幅，记下过它完整时候的样子；今天地上剩下的，是遗址。

馆里整理这套图的人给你留了一封信，请你来现场走一趟。信封没拆，说好了到遗址门口再拆。随信还有一份没走完的档案，愿意看的话，一并交到你手上。

档案夹的封面印着：西洋楼铜版图。你先翻一翻。

二十幅，一幅一号。图录里写着，乾隆四十六年到五十一年，宫廷画家伊兰泰起稿，造办处刻版刷印，贺清泰、潘廷璋这些在宫里当差的西洋画家也搭过手。画的是刚建成的样子，喷泉、石柱、楼顶都在，一样不缺。这些都是常识。

让人停住的是夹在后面那张民国著录卡。「第二十图」的条目后面，有人用铅笔补了一行小字：闻有第二十一图，未见。你把图名清单从头数了一遍，一到二十，盛景收完。第二十一行不在清单里，空着，没有着落。

再往后翻，类似的说法零星还有几处。有人说它被藏起来了，有人说根本没画完，有人说它早就和楼一起烧成了灰。谁也没拿出过实证。这些话就夹在档案的缝里，拔不掉，也按不平。

二十页图里，只有黄花阵那一页后来多夹了一张照片，回形针还别着。正面像一处工地，矮墙的走向和画上的迷宫几乎一样，没有任何说明。翻过来，背面有一行钢笔字：照原图，复位。1987、1989。

照这行字说，那道墙是一九八几年的人照着这张画重新砌起来的。字现在就能读；可墙到底新不新、跟画对不对得上，隔着纸说不清，得到跟前才算数。

每一页的边上留着一道空栏，印着两行小字：对得上的，划个勾；对不上的，记下来。最底下压着一份封套，封口上写着一行字，到像下拆。

铜版画上，楼是完整的。条目旁边不知是谁抄了半句乾隆自己的话：水法不过工巧之一端……中国之大，何奇不有。

后来楼烧了。画还在。

邀请写的就是这儿。到了门口，再拆信。

【导航】西洋楼遗址入口。

## 【散页】顺路：谐奇趣

（整段可跳。跳过：正页一个字不少，直接去黄花阵。）

还没到迷宫，先撞见一处废墟。

说撞见，是因为你本来没打算停。绕过一道土坡，一片汉白玉的残基横在眼前，比想象中大得多。台基上还立着几根柱子，柱头的卷草纹让风磨圆了，花瓣的层数倒还数得清。

档案里多出来的这一页写着：这里叫谐奇趣，乾隆十六年秋天建成，是西洋楼里第一座盖起来的欧式水法大殿。主楼三层，楼前两侧各有一排琉璃厅。按档案的说法，皇帝在正楼进膳，东侧的厅奏中乐，西侧的厅奏西乐，楼前看喷泉。

这句话你读了两遍。东侧，西侧，中乐，西乐。

他坐在正中间。左边一套乐队，右边一套乐队，同时响。

说实话，第一眼你觉得有点贪心。两种乐器凑到一块儿，能好听到哪儿去。

**【现场·听】** 不设谜题。站到台基中间。左声道中乐（笙、笛、琵琶），右声道西乐（提琴、管风琴），先分开，再叠上。听多久自己定。音频结束不催下一站。

结束语：当年他就坐在你现在站的位置。左边中乐，右边西乐，一起响。

站在中间听了一会儿，好听不好听倒不打紧了。两边的东西都是他自己挑的，都要，那就并排摆在自己手边。

听完，掏出那张卡片，试试纸上的楼和地上的楼，还对不对得上。

**【道具·取景框卡】** 硬卡中间镂空，印着谐奇趣主楼的线稿。举起，闭上一只眼，让线稿对眼前的台基和残柱。烧的是梁柱门窗，石头台基还在，所以轮廓还能对上。对上就是对上了。  
卡背为散页残片（谐奇趣轮廓）。**不进结局必需拼图。**

纸上的线条落在石头上，位置差不多。画是两百多年前的，石头是眼前的，中间烧过一场火，居然还咬得上。

南边有一口海棠形的水池。档案上说，池里原先有铜羊、铜鸭，还有一条西洋式的翻尾石鱼，一起喷水。你沿着池边走一圈，基座的痕迹还在，鱼不在了。

合上档案，往黄花阵走。走出池子口，回头看了一眼那个空着的基座。

## 第二站：黄花阵（主线）

信封把你指到这儿。黄花阵到了。齐腰高的砖墙在草地上排开，一眼望不见里面的路。

皇家园林里修迷宫？你的第一反应是，这儿又不是游乐场。

先翻夹照片的那一页。正面是一幅画，画的也是这座阵，不过是夜里的：一群人提着灯，正往中心亭跑。画上的墙和眼前的墙对得上；画上的人，大白天一个也没有。

先对这一处：纸上有人，地上没有。小程序问，他们在干什么。不设选项，想到什么答什么，沾边就算过。

**【对读1】灯戏图 vs 空墙**（卡住才出。主路径就是上面那句「他们在干什么」。）

- 通过：中秋 / 灯 / 宫女 / 玩 / 赏。
- 揭晓：中秋夜，皇帝坐阵心凉亭，宫女跑阵，先到有赏。
- 卡片数字：年1＝**2**

原来是个中秋灯会。皇帝坐在阵心的凉亭里看，宫女们提着灯在阵里跑，谁先到中心谁领赏。好嘛，不出门也有得玩。

小程序发来头一张卡，角落印着个数字，2。先收着。往后每对上一处，就来一张。

再对同一幅画。跑阵的人手里都提着一盏灯，灯是黄的。这地方又叫黄花阵。小程序追问，「黄花」两个字，是不是打灯上来的？

**【对读2】还是这一页**（卡住才出。）

- 答案：黄绸莲花灯。
- 卡片数字：年2＝**0**

是。黄绸扎的莲花灯。名字就是从这灯上来的。又一张卡跟着到了，数字是 0。

画上看不出迷宫难走不难走。中心亭就在那边，路得自己用脚找。墙上一路都是同一种花纹，先不急，留意着走。

档案里还配着一张俯视卡，墙印在纸上，路是空的。拿着它进阵，路自己挑，走错了退回来，站上中心亭，这一段就算完。

**【走】** 俯视卡，墙印上，路是空的。走到中心亭即过。不判分。

走到中心，是一座八角亭。档案里另一页画着这座亭的线稿。举起来抬头对，一眼就能看出个怪处：顶是西式的圆穹顶，檐却翘着，是中式的飞檐。再细对，纸上的线和眼前的亭子，有的地方对得上，有的对不上。对得上的，拍下来。

**【对读3】亭子线稿 vs 眼前这座亭**（走到了才对。卡住才出细目。）

对上其中即可：

1. 西式穹顶 + 中式八角飞檐
2. 檐角立饰（西式凉亭檐口是光的）
3. 中式莲座 + 西洋宝瓶花苞
4. 双天鹅纹里藏蝙蝠

卡片数字：年3＝**2**  
正页残片·一（亭与墙）。

拍完点个「记下了」，第三张卡到了，数字是 2。档案夹的格子里还翻出一片残片，亭子和墙的轮廓。

出亭子的时候，顺着墙走。档案里另有一页，印着四种花纹图样。把纸举到墙跟前一处一处比，别贴着。这一路看到的那种纹，纸上有。

**【对读4】纹样页举纸对照**（不是四选一测验。是举纸对墙上的纹。）

- 答案：万字纹。不是「水」。
- 卡片数字：年4＝**6**

对上的那一张，到小程序里点「我认出了」，是万字纹，这一路墙上看到的就是它。第四张卡随着到了，数字是 6。

这时再把那张照片翻过来。背面一行钢笔字：照原图，复位。1987 年、1989 年。

原来刚才在里面走错又退回来的那道墙，是一九八几年的人照着档案里这一幅画，一块砖一块砖重新砌起来的。离墙近一点看就知道，砖是新的，砖缝是新的，两百年前的墙不会这么齐。这行字你早读过，看完砖，它才跟眼前的东西对上。

## 【支线】顺路：方外观

（可跳。容妃按《清史稿》有载。「香妃」「体有异香」是传说，不跟史料混讲。不写言情。）

再往前几十步，是一座三开间的台基，方方正正。剩得不多，柱础，几级石阶，半截墙。可地方选得讲究：前面有池子，后面正对一片开阔地。

档案里关于这座殿，只有一行字。对着那行字确认两遍才敢信，这里原来是一座礼拜殿。方外观，乾隆二十四年建成，殿里供着阿拉伯文的碑刻，是给一位维吾尔族的妃子做礼拜用的，容妃，民间叫她香妃。档案特意注了一笔：容妃在《清史稿》里有记载，人是真的；「香妃」「体有异香」那些说法，是民间传说，没有实证。

那一行字后面还有半句：说她每次来，乾隆都陪着来。

但他不进去。

正对面是五竹亭，中间隔一座五孔石桥。一个人在殿里礼拜的时候，如果有人陪她来，就在桥那头的亭子里。档案没写谁在那儿等过，也没写等了多久。就那么一行字。

**【道具·纹样对照卡】** 六种纹样：番花、卷草、贝壳、莲花、缠枝、几何回纹。现场能找到的，铅笔在方格里划一道。档案上的数目和你数出来的对不上。两个数都记下。  
散页残片·纹样卡。

**【道具·等候卡】** 正面：台基和五竹亭位置。背面空白，一行浅字：你在外面等过谁？想到就写。不拍照，不提交，不进留言池。写完自己收着。音频结束语：写完就收起来吧。这张不用给我看。

你绕着台基走两圈。有几种纹样确实找到了，有几种怎么也找不着，可能在那半截墙的背面，也可能早就没了。档案上的数目和你数出来的对不上。两个数都记下来，不用纠哪个对。

这一站没有题，也没解开什么。她每次来，他陪着来，然后站在门外。

## 第三站：海晏堂（主线）

海晏堂到了。废墟摊在低洼地里，一路铺开看不到头。扇形的水池干着，池底积着落叶。两侧本来各有一列兽首的石座，一侧还认得出一排，另一侧几乎平了。

入口抄的那半句，到这儿才见着实物。他把水做成了钟。

档案翻到这一页，画上十二个兽首一齐对着池子喷水。再低头看地上，池是干的，座还在，喷水的兽首不在了。

画上这十二尊，也不像光为了好看。它们是轮着喷的，一尊管一段，像在值班；画的一角还空着一格，像是等人补上。这是在干什么？

小程序翻出三格小画，头两格是鼠和牛，各标着子时、丑时，第三格空着。问的是，照这样排下去，十二尊一齐喷，该是哪个时辰。

**【对读1】喷泉页 vs 干池空座**（卡住才出三格。）

12. **两条新红线（2026-09-11 二稿口径同口径清理）**：①全程不触摸文物——看砖不摸墙、举纸不贴墙、水显只涂自家道具纸；本稿已按此把「摸墙验砖」改「离墙看砖」（看砖色、砖缝）、「贴墙」改「举纸对照」、「一路摸过的墙纹」改「一路看到的墙纹」，回响信删「你摸过那道墙。」一句（唯一动信处）。②不替游客编感受和动作——不写「愣住、看了很久、对了半天、站了挺久、没往眼里去、感觉就来了、盯了很久才反应过来」这类句；动作用指引句（回头看／看看中间那块空白／站到底下仰头看），去不去、停多久是游客的事。后续任何道具与文案不得以接触文物本体为前提。
