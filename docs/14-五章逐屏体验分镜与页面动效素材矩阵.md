# 五章逐屏体验分镜与页面、动效、素材矩阵

## 1. 文档定位

本文把 [12-剧情体验与交互呈现完整计划](12-剧情体验与交互呈现完整计划.md) 和 [13-五章八互动阶段 A 详细矩阵](13-五章八互动阶段A详细矩阵.md) 转换为可直接用于线框图、高保真视觉、动效分镜、素材拍摄和前端原型的逐屏设计规格。

已确认的产品边界：

- 五地点及顺序固定：黄花阵 → 海晏堂 → 大水法 → 远瀛观 → 雨果雕像。
- “十二兽首回归与历史记忆”的核心主题固定。
- 各地点知识目标固定。
- 剧情人物、剧情载体和具体玩法可能变化。
- 正常现场与阅读页面采用明场遗址档案风；每章重点结果和终章进入克制暗场。
- 第一版面向大众成人游客。
- 正式事实画面以现场实拍和可靠资料为基础，AI 只辅助纹理、概念帧和明确标注的示意表现。

本文中的 65 个主线屏幕是当前推荐的 `storyboard-v0`，不是永久写死的代码页面。人物或玩法变化时允许替换、合并或拆分屏幕，但必须保持：

1. 五地点顺序不变。
2. 每个固定知识目标都被明确覆盖。
3. 现场 → 观察 → 内容/玩法 → 发现 → 转场的因果关系不被破坏。
4. 新内容包具有完整、唯一、可恢复的屏幕后继。
5. 旧 session 继续固定原内容版本，不混入新人物、玩法或素材。

## 2. 视觉与体验基线

### 2.1 核心视觉概念

```text
行走中的遗址档案
```

明场层：

- 旧纸白 `#F2E8D6`：阅读、地图、档案和工具包基底。
- 墨石黑 `#202A29`：正文、轮廓和现代操作层。
- 汉白玉灰 `#AAA397`：遗址、分隔和静态信息。
- 氧化铜绿 `#58756F`：知识结构、水线和已确认状态。
- 旧铜金 `#987044`：重要物件和回归状态。
- 朱砂红 `#A64F43`：当前动作、关键标记和引用定位。

暗场层：

- 深墨背景建议 `#141B1A` 至 `#202A29`，避免纯黑。
- 旧纸白作为主要文字色。
- 旧铜金只照亮关键结果，不形成游戏霓虹。
- 未知和缺口使用轮廓、纹理、文字共同表达，不只降低透明度。

### 2.2 页面构成原则

- 地点主视觉占首屏约 60% 至 70%，不放进统一白卡。
- 每屏只保留一个主要动作。
- 同一屏只使用一个主要叙事载体。
- 现场照片、信件、档案、手记、铜板和地图具有不同材质层级。
- 操作说明使用现代黑体体系；标题、引文和档案标题使用宋体体系。
- 不长期显示十二兽首收集条，只保留章节进度、工具包和地图入口。
- 关键触控区域不小于 44×44px 等效尺寸。
- 不使用卡通生肖、糖果渐变、赛博霓虹、emoji 图标和无因果庆祝粒子。

### 2.3 屏幕与真实页面的关系

“屏幕”表示用户看到的一个完整视觉状态，不等于必须创建一个小程序路由。

| 屏幕类型 | 建议承载方式 |
|---|---|
| 序章封面 | 序章首页页面 |
| 到达、观察、剧情载体、玩法、结果、物件 | 同一章节体验页内部切换 |
| 地图、行程、到达确认 | 地图转场页内部切换 |
| 工具包、手记、档案、来源 | 独立页面或不改变主线游标的覆盖层 |
| 时间线、终局、结语、留言 | 终章页内部切换 |
| 记录详情 | 路线完成后的独立只读页面 |

## 4. 全局页面与动效语法

### 4.1 通用页面骨架

| 区域 | 设计要求 |
|---|---|
| 顶部安全区 | 章节进度、地点名、地图和工具包入口；不展示完整收集条 |
| 现场层 | 满幅照片或审核后示意，明确现场/复原/示意标签 |
| 内容层 | 每次只出现一个观察、剧情、档案或结果单元 |
| 操作层 | 底部一个主按钮；提示、来源和辅助操作降为次级入口 |
| 状态层 | 加载、弱网、减少动态、现场不可达和辅助完成状态 |
| 返回行为 | 返回不回退已完成 beat，不重复发放物件，不清除当前玩法快照 |

### 4.2 动效时间与性能

| 动效类型 | 建议时长 | 规则 |
|---|---:|---|
| 点击反馈 | 100 至 160ms | 轻微明暗或 `scale(0.98)`，不改变布局 |
| 内容进入 | 180 至 260ms | 淡入 + 8 至 12px 轻位移 |
| 纸张展开 | 240 至 320ms | 使用缩放、位移、遮罩；不模拟复杂 3D 翻页 |
| 场景进入玩法 | 300 至 400ms | 保留共享现场对象，使用裁切、放大和叠层 |
| 章节重点结果 | 450 至 600ms | 每章恰好一个重点效果，用户可立即跳到终态 |
| 退出 | 进入时长的约 60% | 退出快于进入，避免拖沓 |

所有核心效果：

- 优先使用 `transform` 和 `opacity`。
- 不等待动画结束才能操作。
- 提供 `reducedMotionVariant`，只保留必要淡入和最终状态。
- 弱机不运行大面积模糊、持续粒子和频繁布局动画。
- 短震动只用于重要物件获得和终局落位。
- 声音默认可关闭，关闭后仍能完整理解结果。

## 7. 重点转场动效分镜

### 7.1 黄花阵至海晏堂

```text
路径点亮
→ 阵心出现数字物件
→ 物件收入工具包
→ 下一地点载体展开
→ 线索组成“海晏堂”
→ 字迹成为地图终点标签
→ 路线绘制到海晏堂
```

共享元素：阵心光点、路线载体、地点字迹、地图终点。

### 7.2 海晏堂至大水法

```text
地支环对齐
→ 十二水线短暂亮起
→ 一条水线离开圆盘
→ 水线成为转场玩法进度
→ 终点形成大水法标记
→ 示意水线淡出
→ 真实路线接管同一位置
```

共享元素：圆盘水线、路线进度、地图路线。

### 7.3 大水法至远瀛观

```text
遗址照片形成玩法分割
→ 互动完成
→ 缝隙消失
→ 复原示意交叉显现
→ 用户比较后回到真实遗址
→ 真实轮廓线向后上方延伸
→ 转为高差路线图
```

共享元素：同视角现场图、轮廓线、高差线。

### 7.4 远瀛观至雨果雕像

```text
三组证据轮廓完成
→ 轮廓汇入数字拓印
→ 拓印附证据编号
→ 拓印翻面显出最后地点
→ 纸面成为地图
→ 雨果雕像现场图展开
```

共享元素：证据线稿、拓印纸、路线地图。

### 7.5 终章

```text
事件卡按时间落位
→ 年份收拢到铜板边缘
→ 获批状态集附加
→ 铜板展开为十二格
→ 非 unknown 卡落位
→ 未知格保持空缺
→ 明场转深墨暗场
→ 状态结语逐屏出现
→ 留言或暂不留言
→ 主动完成并生成记录
```

共享元素：年份刻度、数字铜板、状态卡、未知空格。

## 9. AI 使用边界

可以使用 AI 辅助：

- 纸张、铜锈、水痕、噪声和不涉及事实判断的装饰纹理。
- 低保真概念帧、动效 storyboard 和布局草图。
- 已有可靠复原依据下的非关键环境补全，且必须标注“复原示意”。
- 无人物、无史实陈述的氛围层和过渡遮罩。

不得由 AI 决定：

- 遗址当前样貌和现场开放边界。
- 五段正式路线、高差和无障碍信息。
- 远瀛观三组证据和正确答案。
- 雨果铭文、法文原文和中文译文。
- 兽首回归年份、机构和公开状态。
- 大水法历史结构和复原依据。

AI 生成物进入原型或生产前仍须记录模型、提示词、输入参考、生成时间、人工修改、表示类型、审核和使用权。

## 11. 设计与原型实施顺序

具体迭代批次、进入条件、交付物和 Gate 见 [15-UI 原型逐步迭代计划](15-UI原型逐步迭代计划.md)。

1. 根据本矩阵绘制 65 屏低保真线框图，先验证信息量、主动作和后继。
2. 建立颜色、排版、间距、按钮、图标、材质和动效 token。
3. 先制作四张高保真关键帧：`PRO-01`、`HHZ-05`、`DSF-05`、`HUG-08`。
4. 编制五地点现场拍摄 brief 和五段路线实走表。
5. 制作 `PRO-01` 至 `HYT-01` 的可点击纵向切片，验证序章、到达、观察、玩法、结果、物件和转场。
6. 使用第二套人物和至少三个替代玩法复测同一页面骨架，确认只替换槽位配置。
7. 在真实手机、户外强光、弱网和减少动态模式下测试。
8. 方向通过后扩展海晏堂、大水法、远瀛观和终章高保真页面。
9. 人物剧情锁定后再制作正式署名载体、长文、语音和配音。
10. 素材来源、授权、digest、fallback 和表现类型全部通过后，才进入生产内容包。

## 12. 验收标准

- 每屏只有一个主要动作和一个主要视觉焦点。
- 用户在进入玩法前能理解玩法来自哪个现场对象或知识问题。
- 玩法完成后能直接看见它改变了什么，不以 Toast 代替结果。
- 更换人物不会影响页面结构、现场素材和知识目标。
- 更换玩法不会影响到达、观察、结果、物件和地图转场。
- 每章恰好一个重点动效，其余只使用短反馈。
- 户外强光下正文、按钮、地图和状态仍可读。
- 所有拖拽玩法具有点选/按钮替代方式。
- 动画、颜色、声音和震动都不是完成知识目标的唯一线索。
- 正式事实画面、复原示意、剧情化道具和产品示意具有明确标签。
- 所有正式素材具备来源、授权、review、digest、变换记录和等价 fallback。
- 弱网、点位关闭和减少动态不会中断主线。
- 完成效果不填补未知兽首状态，不制造虚假完整结局。
