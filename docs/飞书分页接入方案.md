# 飞书分页接入方案

正文：飞书《第廿一图》v3 revision **5614**。
这份是地图、音频、玩法的共同底稿。先按页定内容，再开发。当前代码仍是 V2 四站（入口 → 黄花阵 → 海晏堂 → 雨果），还没按本方案改。

## 三条约定

1. **字只用正文原句。** `DJ` / `SL` 编号、设计意图、互动玩法标题不上屏。不另写图注、解说、按钮旁白。
2. **实体道具不画在页面上。** 用户自己拿着。该用的那一页只提示去用。小纸片按文档写在序章正文里，不当成单独道具图。容妃图、火烧视频、四张花纹题面是小程序画面，不是实体道具。
3. **一页一条旁白。** 文件名 `narr-<页号>`。只念「旁白」栏。不念选项字母、按钮、史料卡正文、道具提示。走路页没有新句子时不配旁白。揭晓换了屏上的字，就换一条，记在同一页的「揭晓轨」。

声线以后用 MiniMax `speech-02-hd`，旁白 `audiobook_male_2`。谐奇趣贴片是声景，不是这条人声。

分两种，不要混用：

- **站与站之间（M1–M7）**：整页就是导航。现在在哪、下一站在哪、距离、开始导航。没有剧情句，不配旁白，不放谜题，不放道具图。这几页不要收成侧边小按钮。
- **已经站在某个点里的页面**（E、X、H、F、HY、XS、DS、HG、FN、LT；序章除外）：侧边放一个小按钮，点开才看到同一张地图。不挡正文，也不代替走路页。

现在代码里的 `map-drawer` 就是这个侧边入口，留在点位页面上。站与站之间另做整页，不用抽屉充数。

纸质路线图是实体道具，走路页不要把那张图再画一遍。地图模块只标点、算距离、打开导航。黄花阵「前往中心亭」是站内指引，不换地图点，也不单开一页导航。

## 过渡、谜题、道具怎么放

每个点都按这个顺序，不把三件事叠在同一屏：

1. **走路页**：上一站最后一句已经点了下一站的名字，然后才进走路页。这一页只有地图，没有谜题，没有道具图。
2. **到站页**：先读这一站的原文。
3. **道具提示**：要用实物时，在谜题前面加一行提示。不画道具，也不在屏上做一套假的。
4. **谜题**：留在这个点上，不放到走路页。
5. **揭晓**：用正文原句。揭晓换了字，就换一条旁白。
6. 原文点名下一站之后，再进下一段走路。

| 道具 | 只在这一页提示 | 屏上不做 |
|---|---|---|
| 小纸片 | 不提示。句子写在 P1 | 不另放卡片图 |
| 档案袋、日记 | P3，打开档案袋、读日记 | 不画袋子和日记本 |
| 纸质地图 | E1，打开地图再做方位题 | 走路页不贴这张图 |
| 二十幅铜版 | E2 提示袋里有铜版；DS1 提示对照《大水法南面》 | 各站不贴铜版 |
| 谐奇趣音乐贴片 | X1 | 不画贴片。声音由手机播 |
| 信封 | X2，拼两半字 | 不画信封正反面 |
| 黄花阵图 | H3，翻面 | 不画宫女游玩图 |
| 花纹道具 DJ10 | H5，选出看到的花纹 | 实物不画。四张题面用飞书里的浮雕照片，那是题目，不是道具 |
| 特刊 | XS1 | 不画特刊 |
| 时辰盘 | HY3 | 不画转盘，不在屏上填生肖 |

两条分开。跳过不是把答案直接揭晓。

**不去这个点。** 只放在走路页 M1–M7。用户这次不想去，就标成「这次没去」，直接进下一段导航。进程页以后还能再去。

**人已经在点里，但不做这道题。** 每道谜题都可以跳过。跳过不播揭晓、不显示答案，进该站下一件不依赖答案的事。揭晓页跟着这道题一起过去。

**游览进程页**随时能开。点位页和走路页的侧边，和地图小按钮放在一起，点开是单独一页，不是又一个抽屉。

这一页只列进程，不写新剧情：

- 序章、八个点、结局、次日信
- 每项是：还没到、这次没去、进行中、已看完
- 点开某个点，下面再列它的谜题：未做、跳过、完成
- 点「这次没去」或「跳过」，回到那一站的走路页，或直接重开那道题

音频：按上表的 `narr-*` 生成。序章只有 `narr-p1`、`narr-p2`、`narr-p3`。走路页 M1–M7 不生成。谐奇趣贴片单独一条声景，不进旁白表。跳过的页不播对应旁白。

地图：只改 `site-geo.js` 的 8 个点，以及 M1–M7 这 7 个走路页。玩法页不内嵌地图。

玩法：只做表里「玩法」栏。实体道具只提示，不在页面里做一套假的。
