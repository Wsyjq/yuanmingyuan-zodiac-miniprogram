# 海晏堂画布滚动与交互修复

用户反馈：喷水画面停留在屏幕固定位置，遮挡其他内容，无法正常操作。

## 修复

- 海晏堂 HY1 使用页面自身滚动，Canvas 不再嵌套于 scroll-view。正文提取为共享 WXML include，其他节点仍使用原阅读容器。
- Canvas 回到正常文档流，明确画面高度；页面滚动位置继续保存与恢复。
- 水钟运行状态由组件持有，事件只保存草稿及更新讲述互斥状态，不同步回灌 state 属性，避免递归更新。
- 测试渲染器增加 WXML include 展开；新增运行状态持久化且不回灌组件的回归测试。
