# 玩法组件开发计划

> 状态：本文保留为八个 legacy 玩法的算法与交互参考。五章版本会重新编排、合并和拆分这些能力，并要求 reducer、标准化 result 与 snapshot codec；流程归属以 [12-剧情体验与交互呈现完整计划](12-剧情体验与交互呈现完整计划.md) 为准。

## 组件开发原则

每个玩法组件只负责当前关卡内部交互，不负责登录、接口、历史记录和页面跳转。

统一输入：

```ts
type GameInput = {
  routeId: string;
  sessionId: string;
  stage: TourStage;
  progress?: StageProgress;
};
```

统一输出：

```ts
type StageResult = {
  routeId: string;
  sessionId: string;
  stageId: string;
  status: 'completed' | 'skipped';
  mark?: string | null;
  completedAt: string;
  payload?: Record<string, unknown>;
};
```

组件事件：

```text
bind:complete
bind:skip
bind:restart
```

## 通用能力

- 每个组件必须支持重置。
- 每个组件必须能从初始状态进入。
- 每个组件必须能在 390px 宽度手机上操作。
- 拖拽对象触控目标不小于 44px。
- 复杂玩法必须支持“跳过此环节”。
- 正式游客版不出现“演示放行”字样。

## 第 1 站：大水法 3x3 拼图

组件名：`dashuifa-puzzle`

### 目标

使用同一张源图做 3x3 背景切片，玩家交换图块复原大水法主视觉。

### 状态

```ts
type DashuifaState = {
  order: number[];
  selectedIndex: number | null;
  restored: boolean;
};
```

### 交互

1. 点击第一块图块选中。
2. 点击第二块图块交换。
3. 每次交换后检查是否为 `[1,2,3,4,5,6,7,8,9]`。
4. 完成后播放复原动画。
5. 输出 `completed` 和牛首印记。

### 小程序实现要点

- 使用 `view` 背景图和 `background-position`。
- `background-size: 300% 300%`。
- 不切 9 张独立图片。
- 图片 URL 来自 stage assets，后续可替换 CDN。

## 第 2 站：接雨露

组件名：`rain-catch-game`

### 目标

玩家拖动承露托盘到正确轨道，接住金色雨露，避开碎石。

### 状态

```ts
type RainState = {
  caught: number;
  round: number;
  trayLane: number;
  combo: number;
  bestCombo: number;
  sequence: Array<{ lane: number; type: 'good' | 'bad' }>;
};
```

### 交互

1. 托盘支持横向拖动。
2. 松手后吸附到最近轨道。
3. 点击“接住本轮”或自动判定当前轮。
4. 接中雨露增加 caught 和 combo。
5. 接中碎石或漏接雨露清空 combo。
6. 接满目标数量后完成。

### 反馈

- `+1` 浮动文字。
- 连击 `Combo xN`。
- 成功金色粒子。
- 失败轻微抖动。

## 第 3 站：信封拼字

组件名：`envelope-word-game`

### 目标

玩家从字块池选择正确字块，拼出“海晏堂”。

### 状态

```ts
type EnvelopeState = {
  slots: string[];
  used: Record<number, boolean>;
  pieces: string[];
};
```

### 交互

1. 点击字块填入第一个空槽。
2. 点击槽位可移除或重选。
3. 点击确认校验 `海晏堂`。
4. 正确后信封翻动，文字显现。

### 视觉

- 旧纸背景。
- 信封翻盖。
- 字块纸片翻入槽位。
- 拼对后“海晏堂”高亮。

## 第 4 站：十二兽首报时

组件名：`clock-match-game`

### 目标

玩家完成兽首与地支时辰匹配。

### P0 匹配

```ts
const answer = {
  鼠: '子',
  牛: '丑',
  虎: '寅',
  兔: '卯'
};
```

### 交互

1. 点击兽首卡片。
2. 点击地支卡片。
3. 正确则锁定组合并点亮轮盘节点。
4. 错误则提示重新选择。
5. 四组完成后输出猪首印记。

### 视觉

- 十二时辰轮盘。
- 中央指针或水力钟视觉。
- 正确后 SVG 水线点亮。

## 第 5 站：方外观三位密码

组件名：`password-clue-game`

### 目标

玩家通过三个现场线索得到密码 `568`。

### 状态

```ts
type PasswordState = {
  found: {
    vine: boolean;
    holes: boolean;
    overlay: boolean;
  };
  input: string;
};
```

### 线索

- 石柱卷草纹：揭示 `5`。
- 水池出水孔：揭示 `6`。
- 硫酸纸重合：揭示 `8`。

### P0 实现

先做点击观察和局部高亮。硫酸纸拖拽可作为 P1 增强。

## 第 6 站：沙盘排序

组件名：`sandtable-order-game`

### 目标

玩家按前六个地支顺序排列兽首：鼠、牛、虎、兔、龙、蛇。

### 状态

```ts
type OrderState = {
  slots: Array<string | null>;
  cards: string[];
};
```

### 交互

1. 上方显示 `子丑寅卯辰巳` 六个槽位。
2. 下方显示打乱兽首卡片。
3. 点击卡片放入第一个空槽。
4. 支持拖动卡片到槽位作为增强。
5. 校验顺序正确后输出兔首印记。

## 第 7 站：黄花阵迷宫

组件名：`maze-path-game`

### 目标

玩家旋转道路模块，使入口连到中心亭。

### 状态

```ts
type MazeState = {
  rotations: number[];
  target: number[];
  walking: boolean;
};
```

### 交互

1. 点击模块旋转 90 度。
2. 点击检查路径。
3. 正确则绘制高亮路径。
4. 小人沿路径移动到中心亭。
5. 动画结束后输出龙首追索中印记。

## 第 8 站：终局十二格拼图

组件名：`final-zodiac-board`

### 目标

玩家将已获印记放入十二格拼图板，形成七完整、一追索、四空缺的终局状态。

### 状态

```ts
type FinalBoardState = {
  placedMarks: string[];
  completed: boolean;
};
```

### 规则

- 完整回归：牛、猴、虎、猪、鼠、兔、马。
- 追索中：龙。
- 下落不明：蛇、羊、鸡、狗。

### 交互

1. 点击印记池中的印记。
2. 印记飞入对应生肖格。
3. 龙首显示半透明追索中。
4. 四个空缺显示灰色虚线。
5. 八枚可用印记归位后触发终章。
