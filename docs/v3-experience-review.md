## 审核依据与边界

依据 v3 原稿、`outputs/第廿一图小程序设计稿/第廿一图微信小程序功能与交互设计稿.md`、本轮用户澄清及现有实现。外部 outputs 中另有 V4/V5 文稿，不自行切换剧本版本。设计稿早期建议与用户后续要求冲突时，以用户要求为准：史料全文完整可读；正文保持现有视觉；互动独立成模块；仅次日彩蛋采用逐字对白；无支付、无独立后端。

游戏目标：剧情提出疑问，现场与实体道具提供发现，互动反馈帮助理解，史料支持深入阅读，个人作品承接体验。没有把每一站改成考试或增加强制拍照。

## 发现与已修正

| 问题 | 修正 | 验证 |
|---|---|---|
| 所有失败共用模糊文案，空输入与答错无区别 | 11 项玩法独立任务摘要与反馈，空选项/空站名先提示操作 | Page 行为回归、模板绑定检查 |
| 长正文后玩家不清楚操作目标 | 互动模块内显示当前任务与完成方式；保留原文和原道具说明 | 开发者工具实际检查蓄水楼排版 |
| 想跳过但仍想了解答案，没有主动解读入口 | 拼字、迷宫用途、纹样、水压、构件归位提供原稿解读；可回题或跳过 | 解读不推进、不伪造通关；跳过保持 skipped |
| 水钟正午揭晓不能被普通帮助入口绕过 | 水钟不提供预先解读，维持预测及演出门控 | 专门回归用例 |
| 文字观察需要先保存子表单再提交，直接提交失败 | 主按钮自动保存非空文字草稿后提交 | 验证实际记录、内容、数量、完成状态 |
| 正常文字观察被判为辅助完成 | 文字与照片同等有效；主动用解读/提示仍记辅助完成 | 全主线行为回归 |
| 回看页面仍可删除照片/文字、修改转盘确认等 | 回看禁用记录编辑及相关事件；作品补录仍通过报告页 | 回看事件不改变已有记录 |
| 中心亭显示其他站点记录 | 仅显示本观察点的记录，终局仍汇总全部 | 数据投影检查 |
| 已听过声景仍需要等音轨结束 | 增加玩家主动确认已听过；NFC 扫描本身仍不代表完成 | 原 NFC/播放回归；未伪称试听验收 |
| 显示内部页号、回看按钮文字含糊 | 页眉显示八站序号/序章/终局/来信，回看按钮显示实际去向 | 开发者工具页面检查 |
| 路线页忽略已有特定地点说明 | 使用路线模型中的实际指引，蓄水楼明确北面高台 | 开发者工具导航页检查 |
| 已署名仍显示空输入和两个作品入口 | 保存后只显示署名资料及底部作品入口 | 模板与全流程回归 |
| 辅助文字偏浅、小触点难点、路线路标受共用 CSS 影响 | 深化辅助字色、26rpx 说明、扩大互动次要按钮触点，隔离路线条布局 | 源码与开发者工具目视检查 |
