## 修复前发现

1. cover 进入旧分页流程，walk 另存一份 run，报告与次日信没有共同完成状态。
2. 照片只有临时路径，换页会丢；照片投稿实际提交固定文字。
3. 支付按钮只写本地付费标志；提交失败被当成待审核。
4. 水力钟三个版本规则不同，新页面在答题前泄露正午答案。
5. 分支音频组件删除 onMute 却仍绑定该事件，揭晓音源可能提前播出。
6. 发布清单误包含 2.25 MiB HTML 原型，主包约 3.23 MiB。现有总包检查使用独立的 4 MiB 项目预算。
7. 原测试中存在已失败的旧页面、旧文案、付费和日期卡断言；新验收须检验真实行为而非保留废弃需求。
