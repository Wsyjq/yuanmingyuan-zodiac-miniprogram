## 三、正文互相打架（编号解决不了）

1. **半字谜做了两遍**  
   DJ-03 背面＝黄花阵半字图；DJ-08＝封口半字拼信背。蓄水楼真正用来指向黄花阵的是 DJ-08。日记背面那张图还要不要印，没说。

2. **DJ-07 放在哪**  
   表上是独立特刊。蓄水楼正文：「**信封里面**似乎有线索【DJ07-物理题】」，下一句才是【DJ08-信封】。物理题是塞进半字信封，还是另有一张报？

3. **雨果也有信封**  
   「档案袋里放着一封同名的信」→「**拆开信封**」→读完「把四张文物卡重新收进**信封**」。这不是 DJ-08（半字、黄花阵）。上一版把信封算进 DJ-14，没单独占号。若 DJ-08 和雨果信封都要买现成信封，清单上是 **两个信封**。

4. **五张残片齐了还「差一样」**  
   线法画：第五块收进夹，「五块残片第一次亮起……似乎还差一样东西」→去雨果。终局拿出来还是五张。缺的是中央空白／日期密码，不是第六张残片。上一版容易读成「还要再做一张」。

5. **容器到底几件**  
   档案袋、档案夹、卡包、附件夹、（荏苒）相册／小册子。先定容器，再数里面的纸。
