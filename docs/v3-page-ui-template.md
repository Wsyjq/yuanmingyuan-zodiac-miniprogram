# v3 页面设计模板（怎么改现页、怎么交互）

不是新视觉系统。壳仍是 V2.3：`page-shell` + 左装订孔 + `tag-no` + 【做】条 + `audio-clip` + 朱砂 `btn-seal` + `history-card`。  
改的是：**主线路由、每一幕的 `stage`、题区交互、三次梯子。**  
游客侧不出现「谜题」。有对错的题取消「先不猜」。门票 `gate` 不改。

### 0.1 有对错的题：统一状态机

```
idle ──提交──► attempt=1 错 → hint1（不泄底）
                 attempt=2 错 → hint2（指到画面/道具）
                 attempt=3 错 → reveal（公布答案）──► solved
       对 ──────────────────────────────► solved
solved → history-card（revealed 也发卡）→ followup 文案 → 下一页
```

不要：无限重试、跳过不发卡、红字「错误」。  
用：`attempt-ladder.js` 记 `attempts / hintLevel / revealed`。  
第三次给答案时选项锁死正确项，按钮改成「记下了」。

### 0.2 一页里不要同时出现两道题

一屏一事。海晏堂不要两问。大水法猎狗过关后再切「北侧是谁」。

## 2. 选择题模板（ABCD / 三选一）

**用来改：** `s2-quiz`、海晏堂正午、蓄水楼、远瀛观。

屏上从上到下：

1. 到站 2–3 句 + 【做】  
2. 题面图（灯戏图 / 漫画 / 特刊示意 / 铜版南面）`double-frame`  
3. 手写批注一句（不泄底）  
4. 问句 `q-title`  
5. 选项列表 `.opt`（现 `s2-quiz.wxss` 已有，开放输入改回这个）  
6. 选中描铜绿；点「就是这样」才判定（不要点一下就交，避免误触算一次）  
7. 错：该项碎裂斜线 + `hint`；对：300ms 铜钉 → `history-card`

**从开放作答重构（s2-quiz）：**

- 删：`<input>`、「说个大概」、`onSkip`、「先不猜」  
- 加：四个 `.opt`，`selected` 再确认  
- `followup` 宫女台词保留（V2.3）

交互节拍：

```
未选 → 确认钮 disabled
选了 → 确认
对 → 史料卡 → followup → 下一题页
错1 → 「再看看画里人手里拿着什么、往哪儿跑。」
错2 → 「夜里提灯往中心亭跑，是在跑阵。」
错3 → 高亮 C，文案「中秋灯会。宫女跑阵，先到有赏。」→ 仍弹史料卡
```

## 3. 多选模板（声景 / 方外观）

新交互，可做在 `waypoint` 加 `mode=scored`，或拆页。

1. 到站文案（谐奇趣不写史上首座、不写水从哪来；方外观不写两层/顶/碑）  
2. 【做】听完再勾 / 对照铜版选三项  
3. 声景：大按钮「听」+ 进度条；播完才展开选项（iOS 必须手势）  
4. 六键 `.opt`，可多选，选中铜绿描边  
5. 「确认」提交  

声景判定：全对，或对≥3 且错≤1 → 成功。否则算失败一次。  
失败1：「再听一次，注意声音进来的先后。」自动或手动重听。  
失败2：「拨弦、拉弦、吹管，还有水。笙和竹板没有。」  
失败3：勾上 A/B/C/F，其余灰掉，「琵琶、小拉琴、西洋箫，和水。」通关句挂【SL06】，选项里的「水法」始终不可点。

方外观失败1：「对照铜版，哪些是这座楼自己的。」  
失败2：「楼体、屋顶、碑。不是喷泉，也不是迷宫。」  
失败3：勾 A/B/C。然后才允许出现那三项 + 容妃名字【SL10】。

## 13. 交互时序总图（一站）

```
transit 墨晕进入
  → 到站 2–4 句 + SL（题前词）
  → 【做】一条
  → 听（可选）
  → 交互（选/听/拖/拍）
  → 确认
      对：history-card（角数字）→ 通关句（题后 SL）→ 朱砂印 → transit 下一段
      错：hint，满三次则 reveal 再走同一条通关
```

关人声：【做】+ 确认足够完成。  
开玩引导只镂空：听、地图、手册、提示、确认。
