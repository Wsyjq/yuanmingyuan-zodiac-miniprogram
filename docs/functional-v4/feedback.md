# 本轮功能反馈对应

这里对应用户最终确认的功能计划，避免把会议讨论或未定剧本误记为已发布内容。完整会议原稿与旧文案保留不动。

| 反馈/约束 | 本轮结果 | 验收 |
|---|---|---|
| 少低头、音频为主 | 统一播放器、文字兜底、默认收起挑战、关闭说明不停止声音 | 播放器状态测试、页面检查；现场注意力比例待走测 |
| 不因拥挤、定位或缺道具卡住 | 路线自由进入、跳过/稍后/回看；地图沿用定位失败可查看的实现 | 连续跳题测试；现场路线开放情况待园方 |
| 原谜题/日期保留 | 原题展开可用，跳过日期题可进终章；不补卡和正确结果 | 跳全程、返回补题测试 |
| 同一故事不同人群 | 保存与切换参与偏好，缺少差异配置时用共同版本 | 偏好持久化与共同回退测试；未编造三套内容 |
| 文化内容可追溯 | 阅读说明、来源索引、分站提示、核验和争议字段、收藏/稍后 | 资料页与配置检查；来源包观点仍标为提供方整理 |
| 纪念与记录 | 可空白/纯文字/照片，编辑、草稿、封存、删除、纪念图；保留原报告 | 记录编辑与分页测试；相册导出须真机 |
| 离园后继续 | 完成时间、次日北京时间解锁、发布过滤、独立页码与媒体进度 | 跨日/月/年测试、未发布深链隐藏；新剧情暂缓 |
| 音乐文件可替换 | 14 曲登记、包外托管配置、开发试听服务 | 元数据、Range 请求、素材清单；正式托管未执行 |
| 不伪造全球编号 | 本地计数撤下；旧数字仅留备份，游客显示私人纪念 | 迁移/编号返回测试 |
| 断网与跨设备 | 本地优先，云身份/私有权限/幂等/冲突选择；无云不阻断 | 模拟云与同步客户端测试；真实云部署验收待执行 |
| 剧情仍需斟酌 | 未写入新剧情或新文化游戏，原题内容仅做配置迁移 | diff 复核 |
