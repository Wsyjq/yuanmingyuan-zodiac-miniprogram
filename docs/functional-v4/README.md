# 第廿一图 · 功能补全交接

本分支基于 `main@6c4c5c3`，实现已确认的功能补全计划。原剧情、原谜题和日期密码保留；本轮没有写入尚未确定的新剧本、三条线上故事或公开留言池。

## 可直接体验

封面 → **路线目录 · 声音 · 私人记录**。原考察页面也有 **行程与声音** 入口。

| 功能 | 当前行为 | 主要实现 |
|---|---|---|
| 现场与挑战分开 | 十个原题页面默认显示当前动作，道具、两级提示和跳题入口；展开后是原题与原剧情 | `components/challenge-gate`、`config/experience.js`、`config/tasks.js` |
| 自由游览 | 目录可到任一章节，跳过日期密码后直达终章；回看不补发答案、卡片或站点成就 | `pages/journey`、`domain/experience.js` |
| 统一声音 | 后台讲解与前台 BGM 分离；暂停、拖动、断点、连续讲解、重试、跨页保持 | `services/audio.js` |
| 静默与休息 | 在“行程与声音”中开启，两分钟仅作参考，可提前结束；静默期间关闭所有声音 | `capabilities/overlay-host` |
| 参与偏好 | 亲子、青少年、成人偏好存入档案；没有差异内容的节点显示共同版本 | `config/experience.js` |
| 资料 | 来源索引、阅读说明与 5 张分站阅读提示；按站点、收藏、稍后筛选 | `config/knowledge.js`、`pages/library`、`pages/reader` |
| 私人记录 | 可无文字、无照片、无署名；草稿、封存后编辑、删除、分页导出纪念图 | `pages/journal` |
| 次日框架 | 北京时间次日 09:00，可配置；持续进入；未发布章节在目录和深链接中均不可读 | `pages/echo`、`config/echo.js` |
| 跨设备私存档 | 未配置云环境时保存本机。启用后手动同步、重试、明确选择冲突版本；采用云端前备份本机 | `services/sync.js`、`cloudfunctions/archive` |
| 真实编号 | 本地伪全局编号已撤下；旧报告仍可看，未接入可信编号服务显示“私人纪念” | session / finale / report |

## 开发检查

```sh
npm test
npm run test:visual
# 已安装 Chrome、未安装 Playwright 浏览器时：
PLAYWRIGHT_CHANNEL=chrome npm run test:visual
```

测试预览器按原生页面/组件配置渲染静态截图，可检查布局与绑定。它不是微信真机，不能据此证明锁屏声音、相册权限或真实云环境已经验收。

## 与本轮期间新 main 的衔接

最终分支已重放到 `6c4c5c3`，保留其小说分页、顺路支线、深读文稿和明信片版式。基础/深读共用全局播放器，六处可选站有独立恢复位置，大水法全站关闭配乐。按本轮“私人记录优先、未发布不展示”的要求，报告明信片保存为私人记录；旧来信 URL 转入统一次日框架，原文字函数仍保留供审定，种子明信片不作为真实游客内容展示。
