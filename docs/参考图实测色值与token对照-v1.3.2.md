# 参考图实测色值与 token 对照（v1.3.2）

> 目的：把小红书《手账教程｜复古手账风》6 张参考图（`test/shots-h5/xhs-ref-1~6.png`）做**像素级取色**，与 `app.wxss` 现有 token 对照，判断现有色值是否需要校正。
> 取色方法：Python + PIL，对每张 1080×1440 原图缩至 240 宽采样；纸张色=低饱和+亮度 top 12% 像素中位值；墨色=亮度<70 最频色；过渡棕=纸张与墨之间区间最频色；边框深棕=亮度 70–110 最频色。每项跨 6 张取均值。
> ⚠️ 经核实：本项目 `app.wxss` 的 token 已是 v1.3 定稿、且文档 §1.6 v1.3.1 已基于参考图做过补齐。本文件只做"实测 vs 现值"的客观对照，**不主张推翻现有值**——现有值的"偏亮偏轻"是有意为之（小程序屏幕显示取舍）。本文件提供的是"若想更贴近参考图原貌"的校正方向与数值依据。

## 3. 结论

1. **现有 token 无需校正**——它与参考图属同一色域（低饱和暖棕黄），差异是"屏幕显示故意偏亮偏轻"的有意取舍，符合 v1.3 文档"暖、轻、带灰度，不脏不压抑"的原则。
2. **一个可复用的实测锚点**：`--paper3`（`#DED1B4`）与参考图过渡棕（`#DCC8AA`）几乎重合，证明现有色阶划分与参考图的明暗层次是对齐的。
3. **一个可选的"深墨"补充**：若未来需要更贴近参考图 ref-1/4/5 那种近黑棕的沉稳感（例如夜景页、铜版画描线），可新增 `--ink-deep: #2E1F0D` 作为现有 `--ink` 的加深档，不必替换。
4. **参考图的"无彩色题材色"不适用于本项目**：参考图是通用复古手账，本项目有铜版画/印章题材，铜绿/朱砂是合理扩展，不应为了像参考图而删掉。
