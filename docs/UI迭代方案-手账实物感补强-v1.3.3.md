# UI 迭代方案（v1.3.3，已基于真实代码修正）

> ⚠️ 本文件已**推翻初版诊断**。初版基于 vision 对**缩图**的审查，误判"手账六件套未落地、纸底太干净"。核实 wxml/wxss 源码后发现：六件套不仅落地，且用量很大（binder 38 文件、note-hand 21 文件、tape 16 文件）；`.paper-grain` 做旧质感（污渍+晕影+纤维）和 `.paper-real`（真实纸纹素材 multiply 叠加）均已到位。**缩图会丢失小而散的手账细节，vision 的"元素缺失"判断不可信。** 本修正版以源码为唯一依据。

## 二、迭代方案（按真实价值排序，均为小改）

### P0｜清理死代码（代码卫生，10 分钟）
- 删除 `app.wxss` 中未被引用的 `.tag-hang` 定义；或保留但在注释标注"已被 st-hang-tag PNG 替代，保留作降级兜底"。
- 顺手 grep 其他可能的死代码手账类（如 `.clip-card`/`.photo-sticker`/`.stitched` 各仅 1 处使用，确认是否仍需要）。

### P1｜拍照页的"档案钩子"（可选，若核实确缺）
- 核实 `photo-check.wxml`：夜景底上是否有旧金角花/编号标签/邮戳等元素让它"仍是档案一页"。
- 若无，在取景框四角加 `.corner`（旧金）+ 右上 `.tag-no` 编号，维持体系连续性。

### P2｜加 `--ink-deep` 重墨档（可选，提升质感层次）
```css
--ink-deep: #2E1F0D;  /* 参考图 ref-1/4/5 实测近黑棕；铜版画描线/双框线/拓印/夜景文字用 */
```
- 不替换 `--ink`，仅作加深档供需要"重墨"质感处。拓印页天然已接近此色。

### P3｜序章定调强化（可选，主观）
- 序章是用户第一印象页，若想更接近参考图的"主图定调"，可在 novel-view 之上加一张小幅铜版画插图（IMG-C 系列）作为视觉锚点。
- 非必须——纯叙事页留白也是一种风格。

---

## 三、明确不做的（避免过度设计）

- ❌ **不要"补落地手账六件套"**——这是基于缩图误判的错误方向，六件套早已落地且用量充分。
- ❌ **不要改 `.paper-grain` 加污渍/晕影**——已实现（3 污渍 radial-gradient + 四角晕影 0.10 + 真实纸纹素材叠加）。
- ❌ **不要给每页堆元素**——会违反单屏≤4 件克制原则，反而像堆砌。
- ❌ **不要改 12 个色 token**——已验证达标。

---

## 四、方法论修正（给后续审查的教训）

1. **vision 不能看缩图挑"小元素缺失"**：邮票齿孔、日期章、手写批注这类元素在 900px 缩图上会小到不可辨，vision 会误判为"缺失"。后续审查手账元素**必须 grep 源码**，不能依赖 vision。
2. **vision 的"吻合度"判断在配色/版式层面可信**（大块色域、版式骨架缩图后仍可辨），这两层 v1.3.2 的评估结论（高度吻合）依然成立。
3. **后续验证流程**：源码 grep 定性 + 取色脚本定量 + vision 只用于配色/版式的宏观判断，三者分工。
