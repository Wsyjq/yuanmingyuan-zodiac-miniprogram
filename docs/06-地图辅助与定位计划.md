# 地图辅助与定位计划

> 状态：本文记录的是 legacy 八站地图方案。五章第一版已改为手动“我已到达”，本模块不请求定位权限、不调用 `wx.getLocation`，marker 也不能越过主线 beat 直接进入章节。目标方案以 [12-剧情体验与交互呈现完整计划](12-剧情体验与交互呈现完整计划.md) 第 7.6、17.2、22.8 节为准。本文保留用于识别和移除旧实现，不能作为当前产品要求。

## 一期定位原则

一期定位用于地图辅助游览，不作为强制打卡门槛。

这意味着：

- 用户不必到现场才能继续下一站。
- 每个站点环节可以跳过。
- 不记录完整 GPS 轨迹。
- 不做后台持续定位。
- 不上传实时位置。
- 不做后端距离校验。

## 一期地图能力

| 能力 | 是否需要 |
|---|---|
| 展示用户当前位置 | 需要 |
| 展示八个站点 marker | 需要 |
| 展示推荐游览顺序 | 需要 |
| 点击 marker 查看简介 | 需要 |
| 从 marker 进入关卡 | 需要 |
| 强制定位打卡 | 暂不需要 |
| 后台持续定位 | 不需要 |
| GPS 轨迹记录 | 不需要 |
| 防作弊校验 | 后续版本 |

## 技术实现

使用微信原生 `<map>` 组件。

定位使用：

```ts
wx.getLocation({
  type: 'gcj02',
  success(res) {
    // latitude, longitude, accuracy
  }
});
```

## 页面交互

1. 用户进入地图页。
2. 小程序请求定位授权。
3. 成功后显示当前位置。
4. 地图展示八个站点 marker。
5. 点击 marker 弹出站点卡片。
6. 用户可点击“查看关卡”进入对应站点。

## 定位失败处理

| 场景 | 提示 |
|---|---|
| 用户拒绝授权 | “需要定位权限才能在地图上显示当前位置，可仍继续体验线路。” |
| 定位失败 | “暂时无法获取当前位置，可查看站点地图继续体验。” |
| 精度较差 | “当前位置可能存在偏差，仅供游览参考。” |

定位失败不阻断玩法。

## 隐私说明

如果使用 `wx.getLocation`，需要确认：

- 小程序隐私协议是否声明定位用途。
- 定位用途描述为“地图辅助游览”。
- 一期定位信息仅在本地展示，不上传后端。
- 如后续上传定位用于打卡，需要重新确认隐私说明。
