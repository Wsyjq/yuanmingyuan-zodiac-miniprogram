### B. 审查中发现的深层问题（用户未点名）

1. **"页面打不开"根因**：PowerShell 批量正则替换把 `\"`（字面转义引号）写进
   `water-clock.wxml` slider 属性 → WXML 编译报 `unexpected character '\'` → **整个
   `plate21/module` 子包编译失败** → walk/report 全部 `navigateTo:fail timeout`。
   同批操作还写入过 UTF-8 BOM（`Set-Content -Encoding UTF8`）。
   → 修复 + **npm test 卫生守卫**（禁 BOM、禁 WXML 标签内反斜杠）。
   **教训：批量改源码禁用 PowerShell 引号替换，用脚本文件/编辑工具。**

2. **文楷字体没生效**：`wx.loadFontFace`（Data URL）时序/兼容不可靠，页面回落宋体——
   "不好看"的大头。→ 改 **`@font-face + base64` 注入 wxss**（渲染层确定生效），生成器统一写入。

3. **WXSS `url()` 不能引本地图片**（渲染层报错）：纸纹等背景须 base64 或 `<image>`。

4. **主按钮文案与动作失配**：locked/回看态下视图自算标签（"继续"实际是"返回当前进度"）。
   → `screen.finalize` 统一派生 `primaryLabel`（在 locked 与 `screen-parts.project` 改写之后）。

5. **回看前进死断**：`engine.reviewNext` 的 `addedInRevision` 判断会在被锁页（跳过的谜题揭晓等）
   处中止回看导航（云端修复合入）。

6. **文案多源重复**：同一指令一页说 4–7 遍（H5"选花纹"×4、H3"翻图"×5、HY1 问题×3、DS1 指令×5）。
   → 七槽位单源模型（见原则 2）。

7. **按钮雨**：H4 同屏 8+ 按钮、报告页 15 个。→ 按钮四级制 + 收纳（见原则 1）。

8. **实体道具/解密页结构过载**：多个动词同屏、道具步骤与提示平铺。→ 一屏一动词 + 道具条 + 题面卡 + 小步栈（见原则 3）。

9. **杂项逻辑**：反馈行 hint 叙事步残留、报告"修改"不开编辑器、H4 小步栈多重高亮、
   retry 文案不指路 —— 均已修（提交 `3f01382`）。

10. **验证方法论**：截图存在**编译竞态**（新旧帧混杂，曾误判"没生效"）。
    → 以 **automator DOM 探测**（元素类名+文本）为准，截图作辅。

## 三、设计原则（后续迭代遵循）

1. **按钮四级制**：L1 主按钮页脚恒 1；L2 次按钮 ≤2；L3 安静动作收「更多」；L4 图标钮 ≤2。
   危险动作红字独立区 + 二次确认。按钮文字不拉字距；箭头随文。
2. **文案七槽位单源**：身份句(story.title)/任务句(tasks.instruction)/道具句(props)/题面句/
   答案句/反馈句/知识句，各占其位；去重三铁律：单源、不复述、组件不训话。
   "先…再…"式 UI 机械引导一律不写。
3. **一屏一动词**：读/取/翻/听/选/拼/拖/拍/确认——超出即拆小步栈（完成折叠、当前高亮、未来不露）；
   实体道具用**状态式道具条**（待取出→已取出→已归还），纸面不模拟实物动作。
4. **视觉（西洋楼）**：汉白玉纸面 `#efe9dd`、墨 `#2e2a24`、铜褐 `#8a6b3f`、石青 `#3d6b72`（唯一高潮色）、
   朱 `#a4453a` 仅印章/危险；纹样用遗址母题（圭角卷云/海棠线/贝壳），**禁外来纹样**（回纹/云雷纹）；
   手写感靠文楷（`Plate21WenKai` 子集 + `@font-face` base64），字体子集由 `test/ornate-charset.js` 驱动。
5. **反馈一行**：固定位置三态（石青完成/赭再试/灰提示），不弹块不推挤；状态 100ms 内可见。
6. **户外可读红线**：正文对比 ≥4.5:1、字号 ≥26rpx、触达 ≥88rpx；信息不单靠颜色。
7. **工程守卫**：批量编辑用脚本文件（禁 PS 引号替换）；`npm test` 含卫生检查（BOM/反斜杠/WXML 配平）；
   资源登记走 `tools/build-ui-ornaments.js` / `resources:refresh` + third-party-lock。
8. **验证方法**：npm test 基线 → automator DOM 探测（截图防编译竞态）→ 真机另行记录，
   不把 harness/浏览器截图当真机。
