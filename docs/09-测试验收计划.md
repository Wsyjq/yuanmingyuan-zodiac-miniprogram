# 测试验收计划

> 状态：本文是当前八站 `p1` 至 `p8` legacy Demo 的回归清单，仅用于保护现有玩法和迁移前行为。它不是五章八互动目标版本的发布验收标准。五章版本以 [12-剧情体验与交互呈现完整计划](12-剧情体验与交互呈现完整计划.md) 第 24、25 节为准；新自动化完成后再替换本文。

## 测试目标

确保小程序版 `归途 · 十二兽首寻迹` 能在无真实接口的 mock 环境下完整跑通，并在接入对方接口后保持流程一致。

## 功能验收

### 线路流程

- 线路介绍页能打开。
- 点击开始游玩能创建 session。
- 八个站点可按顺序进入。
- 每站可完成。
- 每站可跳过。
- 完成或跳过后可进入下一站。
- 终局页可打开。
- 终局完成后可生成记录。

### 进度恢复

- 退出后重新进入能检测进行中 session。
- 能弹出“继续上次进度 / 重新开始”。
- 继续后恢复当前站点。
- 继续后恢复已获印记。
- 继续后恢复已跳过站点。
- 重新开始后旧 session 标记 abandoned。
- 重新开始后新 session 从第 1 站开始。

### 记录

- 完成后记录进入历史列表。
- 记录列表展示线路名称、时间、进度。
- 记录详情展示每站状态。
- 跳过状态在详情中可见。

### 地图

- 地图页能展示站点 markers。
- 授权定位后能展示当前位置。
- 拒绝定位不阻断体验。
- 点击 marker 能查看站点信息。
- marker 可进入对应关卡。

## 玩法验收

| 玩法 | 验收点 |
|---|---|
| 大水法拼图 | 可交换图块，复原后完成 |
| 接雨露 | 托盘可移动，接中有反馈，达到目标完成 |
| 信封拼字 | 可拼出海晏堂，正确后完成 |
| 时辰匹配 | 鼠子、牛丑、虎寅、兔卯可匹配 |
| 方外观密码 | 可通过线索输入 568 完成 |
| 沙盘排序 | 鼠牛虎兔龙蛇排序正确完成 |
| 黄花阵迷宫 | 路径正确后小人移动到中心 |
| 终局拼图 | 七完整、一追索、四空缺状态正确 |

## 移动端触控验收

- 390px 宽度可用。
- 375px 宽度可用。
- 拖拽时页面不误滚。
- 按钮触控目标不小于 44px。
- 横向内容可滑动。
- 底部按钮不被安全区遮挡。

## 数据验收

- `routeId` 全链路保留。
- `sessionId` 全链路保留。
- `stageId` 全链路保留。
- completed 和 skipped 都能保存。
- final completed 能保存。
- records 能从 session 生成。

## 接口接入验收

接真实接口后验证：

- 用户信息接口可用。
- 线路配置接口可用。
- 开始 session 可用。
- 当前 session 可恢复。
- 保存站点进度可用。
- 结束 session 可用。
- 历史记录可用。
- 记录详情可用。
- token 失效能进入登录流程。
- 网络失败有友好提示。

## 权限验收

- 定位权限说明合规。
- 拒绝定位时不阻断线路。
- 用户可继续使用非地图玩法。
- 如果后续上传定位，需要重新验收隐私协议。

## 性能验收

- 首屏加载不依赖所有大图。
- 当前关卡资源按需加载。
- 分包体积符合微信限制。
- 动画无明显卡顿。
- 长列表记录不卡顿。

## 回归测试清单

每次改玩法或进度逻辑后至少跑：

1. 全部八站正常完成。
2. 第 3 站跳过后继续。
3. 第 6 站退出后继续。
4. 终局前退出后继续。
5. 进行中 session 选择重新开始。
6. 完成后查看历史记录。
7. 拒绝定位后继续体验。
