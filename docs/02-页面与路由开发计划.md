# 页面与路由开发计划

> 状态：本文记录的是 legacy 八站页面和路由。五章版本不允许通过 `stageId` 或 marker 越过当前 beat，并增加手动到达、可玩转场和显式终章收口。目标方案以 [12-剧情体验与交互呈现完整计划](12-剧情体验与交互呈现完整计划.md) 为准。

## 一期最小页面

一期只围绕 `归途 · 十二兽首寻迹` 一条线路形成闭环。暂不开发社群、商城、课程完整页面。

| 页面 | 建议路径 | 必要性 | 说明 |
|---|---|---|---|
| 线路介绍页 | `pages/zodiac/index` | 必做 | 线路背景、开始游玩、继续进度入口 |
| 关卡页 | `pages/zodiac/stage` | 必做 | 动态承载八个站点与玩法组件 |
| 地图辅助页 | `pages/zodiac/map` | 必做 | 展示当前位置、站点点位、推荐路线 |
| 终局页 | `pages/zodiac/finale` | 必做 | 十二格拼图、最终文案 |
| 记录列表页 | `pages/zodiac/records` | 必做 | 展示历史游玩记录 |
| 记录详情页 | `pages/zodiac/record-detail` | 必做 | 展示单次游玩详情 |
| 玩法调试页 | `pages/zodiac/dev-playground` | 开发期必做 | 独立调试八个玩法 |

## 页面流程

```text
进入线路介绍页
  -> 检查当前用户是否有进行中 session
    -> 无 session：显示开始游玩
    -> 有 session：弹出继续上次进度 / 重新开始
  -> 进入关卡页
  -> 每站完成或跳过后保存进度
  -> 八站结束后进入终局页
  -> 终局完成后结束 session
  -> 生成游玩记录
  -> 可查看记录列表和详情
```

## 线路介绍页

### 功能

- 展示线路标题、主题文案、预计时长、八站概览。
- 展示核心规则：七枚完整印记、一枚追索印记、四尊空缺。
- 提供“开始游玩”按钮。
- 如果存在进行中 session，弹出“继续上次进度 / 重新开始”。
- 提供历史记录入口。
- 提供地图辅助入口。

### 进入时逻辑

```text
onLoad
  getBootstrap(routeId)
  getCurrentSession(routeId)
  if session.status === in_progress
    showResumeModal()
```

## 继续 / 重新开始弹窗

### 触发条件

用户重新进入线路且存在未完成 session。

### 按钮

- 继续上次进度：跳转到 `currentStageId` 对应关卡。
- 重新开始：旧 session 标记为 `abandoned`，创建新 session，从第 1 站开始。

### 默认建议

不要直接覆盖旧进度，避免误操作导致记录丢失。

## 关卡页

### 参数

```text
routeId=zodiac-return
stageId=p1
sessionId=xxx
```

### 结构

```text
StageShell
  ProgressHeader
  MarkStrip
  StageSceneCard
  CurrentGameComponent
  ActionBar
```

### 行为

- 根据 `stageId` 加载对应站点配置。
- 根据 `gameType` 渲染对应玩法组件。
- 玩法完成时调用 `saveStageProgress`。
- 用户跳过时同样调用 `saveStageProgress`，status 为 `skipped`。
- 保存成功后进入下一站或终局。

## 地图辅助页

### 功能

- 展示用户当前位置。
- 展示八个站点 marker。
- 展示推荐游览顺序。
- 支持点击 marker 查看站点简介和“前往关卡”。

### 不做

- 不强制打卡。
- 不后台持续定位。
- 不上传实时位置。
- 不记录完整轨迹。

## 终局页

### 功能

- 显示十二格拼图板。
- 已获得印记可归位。
- 龙首显示追索中。
- 蛇、羊、鸡、狗显示空缺。
- 完成后展示终章文案。
- 调用 `endSession` 结束游玩。

### 跳过站点的影响

需要通过配置决定：

```ts
skipRule: {
  givesMark: boolean;
  countsAsProgress: boolean;
}
```

## 记录列表页

### 字段

- recordId
- routeTitle
- startedAt
- endedAt
- status
- completedStageCount
- totalStageCount
- markCount

## 记录详情页

### 字段

- 线路基础信息。
- 每站状态：完成 / 跳过 / 未完成。
- 每站获得印记。
- 终局完成状态。
- 开始时间和结束时间。

## 玩法调试页

开发期必须有，避免每次都走完整流程。

### 功能

- 选择任意玩法组件。
- 注入 mock stageConfig。
- 查看组件输出的 `StageResult`。
- 重置组件状态。
- 模拟 completed / skipped。

## 页面开发顺序

1. 玩法调试页。
2. 关卡页和 StageShell。
3. 线路介绍页。
4. 终局页。
5. 地图辅助页。
6. 记录列表页。
7. 记录详情页。
