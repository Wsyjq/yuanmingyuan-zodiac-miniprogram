## 4. 建议整改决策

### 首选：替换 bundled 文件

该路径不依赖无法控制的历史账号和第三方补证，交付确定性最高。

1. AI 13 个文件：换为项目自制、委托创作且合同明确转让/许可商业权利的素材，或证据链完整且条款明确允许当前商业场景的生成素材。
2. 历史扫描 3 个模块文件：换为 item 页面明确标注 `CC0`、`Public Domain Mark` 或等效商业开放许可的数字扫描。
3. `assets/host/IMG-F06.jpg`：必须由替换后的模块 `IMG-F06.jpg` 同步复制，不得形成第二条来源链。
4. 每个替换文件在接入前保存来源页、许可快照、原始文件哈希、处理记录和最终哈希。

### 备选：补齐当前文件证据

AI 图片须取得平台和底层模型的完整授权链；历史扫描须取得曼彻斯特大学或其他有权方对具体数字文件的书面商业及改编许可。任一关键材料缺失，资源项继续保持 `hold`。

## 6. 放行门槛

商业候选版本必须同时满足：

1. `third-party-lock.json` 中不存在 `bundled: true` 的 `hold` 或 `rejected` 资源。
2. 所有受控图片都有唯一资源归属、最终哈希、证据文件和准确包状态。
3. `npm test` 通过。
4. `npm run audit:images` 输出与 lock 一致。
5. `npm run check:commercial` 通过。
6. 项目版权责任人在下表完成审批。
