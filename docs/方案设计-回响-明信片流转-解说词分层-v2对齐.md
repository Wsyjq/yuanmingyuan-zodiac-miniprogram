## 0. 总纲：三板块在整体结构中的位置

v2 已把结尾拆成三层，并写明各自职责：

> 结局收束叙事，回响处理情绪，拓展交还主动权。

| 层 | 内容 | 三板块归属 |
|---|---|---|
| 途中 | 12 个点位的行进体验 | **解说词分层**（基础层/深讲层）＋明信片采集点 |
| 结局 | 档案夹拼合 → 反转 → 考察报告定格 | （已有，不属本次） |
| 回响 | 次日一封信 | **次日回信** |
| 拓展 | 回家后可选深挖 | 明信片的第二个提交入口（水车说法） |

三条产品红线贯穿三板块（源自 v2 明示或其设计哲学的直接推论）：

1. **不结算**：不出现步数、用时、完成率、百分比——"那些数字会把两小时的经历压成一个分数"。
2. **不社区化**：玩家之间的接触永远是单张、匿名、隔空的，不做留言墙、不做互动。
3. **可选性**：深讲层、拓展、投递，全部"想就做，不做体验也完整"。

## 1. 板块一：回响（次日回信）

### 1.1 定位

整个产品唯一的"售后触点"：处理情绪，不再给任务。它是档案主人（NPC）与玩家关系的收束——从"我交给你一份残档"到"我读了你的明信片，档案比昨天多了一页"。

### 1.2 触发与形态（v2 硬约束）

- **触发**：离园次日上午，一条推送。**不催、不追、不再有第二条**；未打开则不做任何提醒。
- **形态**：是一封信。竖排信纸样式，一直往下读，**读完没有按钮**——不是弹窗、不是海报、不是分享卡。
- 产品约束提示：小程序的"次日推送"依赖用户在完成主线时自愿订阅一次；未订阅的玩家由报告页的封蜡信入口兜底（当天显示"明日启封"，次日出信），不额外提醒。

### 1.3 信件结构（v2 文案为权威稿，标注"可直接用"）

信件主体固定，共两个动态位：

```
见字如面。
……（固定主体：坦白蓄水楼深讲层空着一栏 → 黄花阵墙的顿悟：
     "有人拿着一幅旧画，把地上的东西补回来了" →
     第21幅不用再找了，它在你在昨天走过的路上）……

[动态段一｜仅投递过明信片的玩家显示]
"你昨天投进信箱的那张明信片，我读了。
 我不打算回答你写的那个问题。我也不知道答案。
 但我把它放进档案了。下一个来的人，会读到你写的那一句。"

[固定收束]
"档案还是残的。不过现在比昨天多了一页。——那个还在整理档案的人"

[动态段二｜运营维护的一行实况]
马首当前所在地（在园/在外巡展及城市、截止日期），无数据则整段隐藏
```

### 1.4 设计红线

- 无任何结算数据；信里**唯一的数字**是马首在哪儿——"一个还在变的事实，说明这件事没结束"。
- 不回应明信片上的问题（"我也不知道答案"），不点评、不打分。
- 信中人设与 NPC 改造方案统一：档案主人 = 长期研究第21图的人，"还在整理档案的人"。

### 1.5 与会议纪要旧口径的差异（详见 §5）

- ~~三分类结语（毁灭/时间/被记住）~~：v2 已无此设计，**弃**。
- ~~信内引用前玩家匿名句 1–3 条~~：前人内容移至雨果站深讲层（见 §2.4），**信内只提玩家自己的明信片**。
- ~~保存/分享导出~~：与"读完没有按钮"冲突，**不做**。

## 2. 板块二：明信片流转（"留言板"的 v2 形态）

### 2.1 定位

不是留言板，是**档案的一页**。玩家之间的对话是一对一、隔空、匿名的：你投进去一张，下一个人读到一张。所有采集的沉淀用途（文创引用、邀请有共鸣的玩家参加活动——会议结论保留有效）都在后台发生，**前台永远不出现"很多条留言"的界面**。

### 2.2 三个采集点，三种规则

| # | 采集点 | 引导句 | 规则 |
|---|---|---|---|
| 1 | **雨果站·明信片**（实体） | "一样东西放在哪儿，才算被保住了？" | 想写就写，可不写；写完**可选**投进现场信箱 → 进留言池；不投自己带走 |
| 2 | **方外观·等候卡**（实体） | "你在外面等过谁？" | **红线：不拍照、不提交、不进留言池**，写完自己收着；音频结束语："写完就收起来吧。这张不用给我看。" |
| 3 | **拓展五·水车说法**（线上） | "如果你以后查到了更靠得住的说法，告诉我。" | 知识型提交入口，整个产品的最后一个动作；不投票、不给答案 |

三处共同点：**产品不做裁判**。不评分、不筛选对错、不展示统计。

### 2.3 明信片本体

- 正面：七根石柱回归时的照片（与四件东西卡之卡三呼应）。
- 背面：空白 + 一行浅色小字（引导句）。约 50 字以内为宜（内容尺度待与甲方定）。

### 2.4 回读机制："一张，不是一堆"

- 位置：**雨果站的深讲层**。下一位玩家走到该站、展开深讲时，随机读到**一张**前人明信片——不是留言列表，不是瀑布墙。
- 展示形态：作为深讲文案中的一页插入（与"那封信"道具同为"读前人之物"的仪式），标注"一位考察者留下的"（匿名，无署名、无日期统计）。
- 换张规则（v2 未明确，**开放问题**，建议）：同一玩家在同一站固定同一张，重看不换、刷新不变，保证"这是一次相遇"而非"刷内容"。
- 内容安全：进池前过滤；被过滤的静默不入池，不影响玩家任何体验。

### 2.5 边界（明确不做）

- 不做公开留言墙 / 匿名句瀑布 / 分类筛选。
- 不做评论、点赞、转发等任何互动。
- 方外观等候卡永远不上传——它的价值就在于"不给任何人看"。

## 3. 板块三：解说词分层体系

### 3.1 分层标准

v2 总纲："以游玩+导览的形式展开，在景点处导入官方讲解。"深讲层已是正式机制（蓄水楼"深讲层空着一栏"、雨果站深讲层读前人明信片、线法画"深讲层可接《圆明园研究》86期"）。据此定两层：

| 层 | 形态 | 体量 | 讲什么 | 铁律 |
|---|---|---|---|---|
| **基础层** | 到站默认展开（音频或文稿） | 约 1 分钟 / 90–150 字 | 方向引导 + 一个知识锚 + 一句生疑/期待 | 知识不求多，先给结论 |
| **深讲层** | "再听一段"折叠入口，玩家主动展开 | 约 2–3 分钟 / 300–500 字 | 史实细节 + 争议口径 + 档案主人线索 + 前人明信片位 | **永远可选，绝不自动播** |

口吻原则（本次只定标准，**播讲稿待剧情整体定稿后统一润色**）：

0. **双通道各自完整**（产品定位 2026-09-10 硬约束）：文字与音频并列——关掉音频时纯文字路径完整自洽可玩；开着音频时文字退为扫读辅助。每一层解说词都按"文稿、播讲稿"两套完整产出版本编写，不是一套稿两种读法。

1. 先给结论再展开；口语化、剧情化、情绪化。
2. 引导词要柔：判断邀请句式（"我发现一个奇怪的地方，你帮我判断一下"），生疑代替出题。
3. 音频四职能：给方向、讲知识（少）、铺剧情、调节奏制造期待。
4. 凡争议处，并列陈述、不下判断（蓄水楼三说为范式）。
5. 口径三级标注随稿走：🟦史料明确可直出；🟨学界共识须注研究方；🟧艺术演绎必须露身份。

### 3.2 十二站点信息点总表（本次核心产出：固化"讲什么"）

> 依据 v2 正文逐站抽取；口径标注挂《权威信源清单-三级标注》《核对详本》。留白站与音频专项是产品结构的一部分，与文案同级重要。

**① 序章 · 西洋楼入口**
- 基础层：信封谜题引导（实体道具：封口半字拼"黄花阵"）；铜版图 20 幅基本事实（1781–1786，伊兰泰起稿、造办处刻印，贺清泰、潘廷璋参与）；"闻有第二十一图，未见"的传闻引入。
- 深讲层：铜版画工艺事实（每版红铜 25 公斤、开幅 93×57 厘米）；皇帝为什么要建西洋建筑群、为何对欧洲建筑水法机械感兴趣（替换 1860 前置说教——会议口径）。

**② 顺路 · 谐奇趣**（音频示范站）
- 基础层：西洋楼**第一座**欧式水法大殿（乾隆十六年秋建成🟦）；主楼三层、两侧九间弧形游廊连八角楼厅；乾隆居中进膳，两侧琉璃厅分奏中西音乐，楼前看喷泉。
- 音频专项：**左右声道设计**——左声道中式乐器（笙、笛、琵琶）、右声道西洋乐器（提琴、管风琴），先各自演奏再叠合；结束语："当年他就坐在你现在站的位置。"
- 留白：不催促、不提问、不接"请前往下一站"。
- 深讲层："这不是欧洲也不是中国，是一个皇帝把两边都搬来摆在自己手边"；南池翻尾石鱼今在北大未名湖、还在水里——引出全篇母题句："**东西不在原来的地方，不一定就是没了**"（结局与回响反复回扣）。
- 道具：取景框卡（铜版画线稿对齐残基，自校验）→ 图样残片·一。

**③ 第二站 · 黄花阵**
- 基础层：中秋迷宫灯会（皇帝阵心观赏、宫女黄绸莲花灯竞走得名"黄花"）；中心亭中西结合四细节（西式穹顶+中式八角飞檐／檐角立兽为中式增设／中式莲座+西洋宝瓶花苞／双天鹅巴洛克纹内藏蝙蝠纹）；墙体万字纹寓福寿绵长。
- 深讲层（**全程最重要伏笔，只陈述不点明，留结局咬合**）：这道墙是 1987、1989 年照铜版画在原址原样修复的——今天的墙与亭不是乾隆原物🟦官网；"黄花阵本身就是一次已经完成的'照着铜版画补全遗址'"，它就是结局"第21图等待后来者完成"的实物证明；官网数据：阵墙总长 1600 余延长米、墙高约 1.2 米。
- 音频专项：音频到"把它重新画回地上的"即止，不解释这意味着什么。

**④ 顺路 · 养雀笼**
- 基础层：中间过道门、两侧原养孔雀珍禽；东面大理石西洋门 vs 西面中式木牌坊——**木头的那一半 1860 年烧了**。
- 深讲层："同一座建筑，一半留下来一半没有；留下来的那一半是石头做的"——物质存续与信息存续的对照，为雨果站"放在哪儿才算保住"预埋。
- 道具：叠层卡（两张半透明卡对光合成本来不可能再见到的完整门）→ 图样残片·二。
- 留白：音频停在"木头的那一半烧了"，之后只有环境音。

**⑤ 顺路 · 方外观**
- 基础层：乾隆二十四年建成的礼拜殿，供阿拉伯文碑刻，为容妃做礼拜用；**口径必须明说**：容妃《清史稿》有载确有其人🟦，"香妃""体有异香"属民间传说无实证🟧，不与史料混讲；乾隆每次陪来、但不进去；正对五竹亭与石桥的空间关系。
- 深讲层：等在门外的人——"他是皇帝，他想进当然能进去。他没进"；本站情绪落点："**能留下来的到底是什么**"（贯穿后半程的提问）。
- 道具：纹样对照卡（六种纹样现场找、铅笔划记；**档案数目与现场对不上，不给答案、产品不做裁判**）→ 图样残片·三；等候卡（写一个你等过的人，**不进留言池——见 §2.2 红线**）。
- 音频专项：结束语"写完就收起来吧。这张不用给我看。"

**⑥ 第三站 · 海晏堂**
- 基础层：切口定为"18 世纪的人怎么让建筑显示时间"（不围着兽首情怀讲）：十二生肖各代表一时辰、到点轮流喷水报时，正午十二首齐喷；今日七尊回归、五尊未归。
- 深讲层：七尊回归名单与时效表述（牛、虎、猴、猪、鼠、兔、马🟦）；马首身世（何鸿燊购回、2019 捐赠国家文物局、2020 划拨圆明园、正觉寺文殊亭专区🟦——与回信动态段"马首实况"同一事实源）；七种纹样（棕叶／茛苕／贝壳／番花／卷草／莲花／海水江岸）配实体转盘；水显纸显影马首。
- 生疑句（转场）："这么多喷泉，没有电泵——水到底从哪儿来？"→ 下一站。

**⑦ 第四站 · 蓄水楼**（生疑站 + 争议站范式）
- 基础层：锡海——楼顶锡板防渗蓄水池，一次蓄水 160 余立方米🟦；水提到楼顶靠高差压力经铜管送各喷口，**不用任何动力**。
- 深讲层：水循环五环（水道→汲水池→水车→锡海→铜管喷口，2015 年考古探明🟦；首尾咬合的拼卡道具即此：不是线，是圈）；**三种水车复原说并列**——人力蹬攀（《圆明园研究》86 期🟨）／畜力齿轮（郭黛姮团队据 Schlimme 复原🟨）／骡拉水车（鸿禧图说🟨）——**不作判断、不给倾向**；设计者蒋友仁（法国人，乾隆三十九年卒于北京🟦）；实际运营真相：皇帝来前太监提水、到即开闸走即关；情绪落点："**连它当年怎么转的，我们都不确定了**"。
- 音频专项：三说各念一遍、中间留两秒空白、底噪不变。
- 道具：量高绳（比台子多高，不判分）＋五段咬合拼卡（自校验）→ 图样残片·四。
- 留白：音频在"一样东西是不是得有人一直在，才算活着"后停止。

**⑧ 大水法 · 留白站**（全程唯一"只待着"的地方）
- **不给道具、不设谜题、不要求任何输入。**
- 音频结构（v2 已定死，逐秒执行）：0:00 一句话"档案上说，这里原来是全园水声最大的地方"→ 0:10–2:10 **完全静默**（不加旁白与配乐，只留现场环境音：风、游客、鸟、远处车）→ 2:10 一句话"刚才那两分钟，你听见的是什么？"（三选一，可跳过；全程唯一一次手机操作）→ 之后不再有音频，下一段需玩家主动点开。
- 设计释义（写给团队）："废墟本身就是一种缺席，静默是唯一诚实的表达方式。"
- **⚠ 与 bgm 资产冲突**：`bgm/bgm-05-dashuifa.mp3`（挽歌）与此站"完全静默"要求相抵触，该曲需重新定位（建议移作回响信页底乐或拓展五配乐），勿进大水法站。
- 待确认（v2 已标注）：两分钟静默是否造成游客滞留、影响现场秩序，需向园方管理方确认。

**⑨ 顺路 · 线法画**
- 基础层：乾隆命人用西洋透视法把画绘在几排砖墙上，从通道一头看平面显纵深；方河（线法山以东人工湖）西岸东望成西方街市；**线法墙今已荡然无存**🟦官网，方河已清整植荷。
- 深讲层：《圆明园研究》86 期样式雷图档结论——两列 11 面梯形收口强化一点透视🟨（引用须点名 86 期）；与方外观容妃线呼应："他没法把她送回家，就在园子最东头用透视法造了一条假的欧洲街"——距离与替代的抒情线。
- 道具：透视框卡＋雪山村庄羊群线稿（半透明，纸上雪山落在空墙上）→ 图样残片·五。
- 留白：音频停在"放下纸，又没有了"。

**⑩ 第五站 · 雨果雕像**（从共鸣升级为真问题）
- 基础层：雨果没来过中国、没见过圆明园，凭掠夺品清单、随军画家速写、报纸文章想象写出《致巴特勒上尉的信》（1861 年 11 月 25 日，真实书信🟦）；2010 年雕像落成，法国雕塑家娜什拉·凯努无偿创作🟦。
- 深讲层：**"两个强盗"是文学修辞，不是对史实过程的描述**——深讲层点明他用的是文学手法不是报道🟧；"他为一个自己从没见过的地方生气，那封信到底替谁写的，说不清"；**前人明信片回读位**（见 §2.4）。
- 站点核心：四件东西卡，玩家自排一列、不排序不评分——
  1. 观水法石屏风：五屏两塔，曾被搬进城内私园，1977 年运回原址装回，**第一件完整回归的流失文物**🟦
  2. 翻尾石鱼：谐奇趣南池那条，今在北大未名湖西侧，没人抢它，还在水里🟦（与 ② 深讲呼应）
  3. 七根汉白玉石柱：流散挪威百余年、完好，2023 年回归🟦
  4. 铜鹿与十只铜狗：1860 年后**无任何下落记录**，"石座还在，东西没了"🟦
- 核心问题（不给答案、不做投票、无点评）："**一样东西放在哪儿，才算被保住了？**"
- 道具：那封信（仿旧信纸 200 字节选，**不用音频朗读，玩家自己读**——"读信这个动作本身就够了"）；明信片（见 §2）；时间轴谜题（1747 建造／1760 核心成／1860 火烧／1861 信／2010 像）。

**⑪ 结局 · 档案夹拼合**
- 五张图样残片异形切口唯一拼法 → 铜版画长卷，中央空白印极浅四字"**此处待绘**"；玩家发现"中间那块空白是我站着的位置"。
- 数字线收束：卡片数字连成今日日期；结局反转文案与报告定格沿用 v2 权威稿。
- 解说词任务：结局不新增知识，只回收母题句（"东西不在原来的地方，不一定就是没了"／"能留下来的到底是什么"／"此处待绘"）。

**⑫ 回响 ＋ 拓展**（线上，见 §1、§2）
- 拓展五项均为"推向真实世界"，解说词只做一句提示级引导，不做长讲：残片背面二十幅图名清单／那套画现在在哪儿（故宫故00009171、国图、北大图书馆、沈阳故宫、巴黎法国国家图书馆、曼彻斯特大学）／含经堂（那套画当年就存在这个园子里——真实的复玩理由）／散在别处的四件（未名湖石鱼、颐和园仁寿门巴洛克门座、大水法石鱼一对 2006-11 回归存展览馆、马首常巡展去前先查）／水车三说提交入口。

### 3.3 与官方讲解的关系

会议已确认甲方有现成讲解词（"你回头找讲解词看就知道了"）。处理原则：**官方讲解词是深讲层的事实底稿，不是播讲稿**——深讲层知识条目须与官方口径一致（尤其年份、数字、兽首时效），再按 §3.1 口吻原则剧情化包装。需向甲方索取：官方讲解词全文、官网"圆明园研究"专栏水景叙事结构（已核：86 期曹新几何学＋水景递次结构）。
