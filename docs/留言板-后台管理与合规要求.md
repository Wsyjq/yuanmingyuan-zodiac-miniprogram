# 留言簿 · 后台管理与合规要求（宿主对接版）

> 版本：v1（2026-09-18，随 Host Adapter 契约 v1.3.0）
> 适用：并入园方小程序 A1 模式。本文是留言簿功能的**后台管理清单 + UGC 合规底线**，
> 与 `plate21/module/contracts/adapter-api.js`（submitBoardMessage / listBoardMessages）配套。

## 1. 机制定位（用户 2026-09-18 拍板）

- **写**在通关当天剧情末尾：report 页「明信片 · 一句话」区之后的「留言簿 · 给后来的人」入口。
- **读**在次日回访：入口首页回访卡、次日之信信末脚注「档案的最后一页，是大家的话」→ 留言墙。
- 玩家自己的话提交后**不立即上墙**（先审后发）；本地始终可见自己的卡片（来自会话 flags，不属公开池）。

## 2. 宿主后台功能清单（运营方可管理）

| 模块 | 要求 |
|---|---|
| 审核队列 | 待审 / 已通过 / 已拒绝 三态；支持按提交时间、机检风险分排序 |
| 机检预筛 | 提交时同步调 `security.msgSecCheck`（含 imgSecCheck 如涉图），风险分带入队列展示 |
| 人工处置 | 通过（进入展示池）/ 拒绝（附可展示原因）/ 删除留存记录可查 |
| 展示池管理 | 已上墙内容可随时**下架**（下架后 24h 内从 listBoardMessages 结果消失即可） |
| 冷启动池 | official_seed 官方预置内容由宿主配置（或沿用模块内置种子池） |
| 追溯留存 | 每条提交留存：sessionId、openid（宿主侧）、原文、机检结果、处置人与时间；留存期 ≥ 90 天（建议 180 天） |
| 举报入口 | 宿主小程序侧提供举报路径（小程序内公示的客服/举报渠道即可）；举报内容进审核队列置顶 |

## 3. 微信平台合规底线（提审前自查）

1. **类目**：留言簿属 UGC 社区互动，宿主小程序类目须覆盖相应范围（如"文娱-资讯/互动"或园区官方类目下允许的评论能力）；若类目不允许 UGC，留言簿功能必须按 §5 降级（只读官方池，关闭提交）。
2. **内容安全**：所有用户提交文本必须先过微信内容安全接口（`security.msgSecCheck`，access_token 由宿主服务端持有）；建议**先审后发**（先发后审需保证 2 小时内处置能力 + 全量巡检）。
3. **未成年人**：不向未实名/未成年人展示不受控 UGC；msgSecCheck 传 openid 启用用户风险维度。
4. **个人信息**：展示池署名一律「一位考察者」，不得透出昵称、头像、openid；后台留存数据仅用于审核追溯，不做二次利用。
5. **用户协议**：提交前页面展示「留言经审核后展示」提示（模块已内置）；宿主隐私政策覆盖 UGC 条款。
6. **数据出境/留存**：留言数据存宿主自有存储（A1 模式零服务器是我们的边界，数据主权在宿主）。

## 4. Adapter 契约要点（v1.3.0）

- `submitBoardMessage({sessionId, text})` → `{status: accepted|pending_review|rejected, reason?, messageId?}`
  - `rejected`：模块 toast 原因、不落已投递态、可改写重投。
  - `pending_review`：模块落已投递态，提示「已收到，审核后会展示给后来的人」。
  - 宿主方法抛错/缺失：模块回落本地 flags 保存（不公开展示），并发 `capability_fallback` 埋点。
- `listBoardMessages({sessionId?, limit=6})` → `{messages: [{text, from, date, source}]}`
  - 只返回过审内容；`from` 固定「一位考察者」；空池返回 official_seed。
  - 同 sessionId 建议固定排序（重看不换）。
- 埋点：`board_message_submitted`（带 moderation=status）。

## 5. 降级矩阵

| 场景 | 行为 |
|---|---|
| 本地开发（local-adapter） | 提交恒 pending_review（不上墙）；展示池=内置官方种子 |
| 宿主未实现两方法 | 同上（模块内回落，capability_fallback 埋点可观测） |
| 宿主类目不允许 UGC | 宿主在后台关闭提交开关（返回 rejected+固定原因），模块退化为只读官方池 |

## 6. 联调验收（建议加入契约测试 CT-15）

1. 提交敏感词样本 → msgSecCheck 拒绝 → 小程序 toast、不落已投递态。
2. 正常提交 → 后台通过 → listBoardMessages 在 24h 内出现该条（from=一位考察者）。
3. 后台下架该条 → listBoardMessages 不再返回。
4. 断网/接口失败 → 提交回落本地保存，重进不丢单（flags 仍在）。
