# NovelView 真机滑动与触觉调参建议

> 更新：2026-08-09  
> 适用组件：`plate21/module/components/novel-view/novel-view`  
> 当前状态：代码、自动化和 H5 触摸逻辑已验证；以下参数仍需在 iOS、Android 真机上做最终 A/B 微调。

## 1. 当前交互基线

- 手指移动不足 `10px` 时不判断方向，避免自然抖动触发页面跟手。
- 初始位移明显偏纵向时锁定为纵向滚动，不再尝试翻页。
- 横向拖动时，纸张最多倾斜 `5deg`，纸角随拖动幅度扩大。
- 松手时满足“距离阈值”或“短距离高速轻扫”任一条件即可翻页。
- 达到翻页距离时触发一次 `light`；纸张落下时再触发一次 `light`。
- 最后一页确认完成时触发一次 `medium`。
- `wx.vibrateShort` 官方定义为约 15ms；iPhone 7/7 Plus 以上及 Android 生效，强度 `type` 需要基础库 2.13.0 以上。

## 2. 可配置参数

组件属性均可在页面 WXML 上覆盖：

| 属性 | 当前值 | 建议范围 | 影响 |
|---|---:|---:|---|
| `turn-duration` | `680ms` | `600-760ms` | 越小越利落，越大越像厚纸；超过 800ms 容易显拖沓 |
| `swipe-distance` | `42px` | `36-50px` | 越小越灵敏，也越容易误触；设为 `0` 时按屏宽 11% 自适应，并限制在 36-56px |
| `flick-velocity` | `0.38px/ms` | `0.30-0.50px/ms` | 越小越容易用短促轻扫翻页；过低会把横向抖动识别为轻扫 |
| `drag-max-angle` | `5deg` | `3-7deg` | 控制拖动跟手时的纸张倾斜；过大会在松手进入完整动画时产生跳变 |
| `haptic-feedback` | `true` | 布尔值 | 总触觉开关；无振动能力时自动无声降级 |
| `settle-haptic` | `true` | 布尔值 | 是否在纸张落下时增加第二次轻震 |

使用示例：

```xml
<novel-view
  title="序章"
  paragraphs="{{paragraphs}}"
  turn-duration="680"
  swipe-distance="42"
  flick-velocity="0.38"
  drag-max-angle="5"
  haptic-feedback="{{true}}"
  settle-haptic="{{true}}"
/>
```

## 3. 推荐预设

| 预设 | 翻页时长 | 距离 | 速度 | 倾角 | 落页震动 | 适用场景 |
|---|---:|---:|---:|---:|---|---|
| 平衡版（当前） | 680ms | 42px | 0.38 | 5deg | 开 | 默认首选，兼顾叙事感与操作效率 |
| 轻快版 | 620ms | 36px | 0.32 | 4deg | 关 | 小屏手机、年轻用户、连续快速阅读 |
| 展陈版 | 740ms | 48px | 0.45 | 6deg | 开 | 现场导览，希望玩家慢读并减少误翻页 |
| 低性能版 | 600ms | 42px | 0.40 | 3deg | 关 | 低端 Android，优先减少桥接更新和动画压力 |

## 4. 症状对应调法

| 真机现象 | 优先调整 | 建议 |
|---|---|---|
| 页面很难翻过去 | `swipe-distance`、`flick-velocity` | 距离每次降低 4px，或速度降低 0.04；不要同时大幅降低 |
| 纵向阅读时经常误翻页 | `swipe-distance` | 提高到 46-50px；必要时把代码中的横向优势比从 1.15 提高到 1.25 |
| 短促轻扫不灵敏 | `flick-velocity` | 从 0.38 降到 0.34，再观察误触率 |
| 松手后动画显得拖 | `turn-duration` | 每次降低 40ms；不建议低于 560ms |
| 拖动到完整翻页时有跳变 | `drag-max-angle` | 从 5deg 降到 3-4deg |
| 纸张显得没有重量 | `turn-duration`、`drag-max-angle` | 时长增加 40-60ms，倾角增加 1deg |
| 每页两次震动太密集 | `settle-haptic` | 关闭落页震动，只保留越过阈值的一次 `light` |
| Android 震感太强 | `settle-haptic` | 优先关闭第二次震动，不要把开始反馈改成 `medium` |
| iOS 感觉不到落页区别 | 触觉模式 | 保留开始 `light`，将完成整卷的 `medium` 作为唯一强调；不要增加长震动 |
| 低端 Android 跟手掉帧 | 拖动更新频率 | 将代码中的 16ms 节流提高到 24-32ms，并把 `drag-max-angle` 降到 3deg |

## 5. 真机验收方法

每台设备连续执行以下动作各 10 次：

1. 正常速度左滑翻下一页。
2. 正常速度右滑翻上一页。
3. 20-30px 的快速轻扫。
4. 20-30px 的缓慢横拖后松手，预期不翻页。
5. 正文区域纵向滚动，预期不翻页。
6. 第一页向右拖、最后一页向左拖，预期只有阻尼跟手，不触发震动或翻页。
7. 连续快速点击下一页，预期动画期间不会重复翻页。

记录以下指标：

- 正常滑动成功率目标 `>= 95%`。
- 纵向滚动误翻页目标 `<= 2%`。
- 慢速短拖误提交目标 `0%`。
- 单次翻页不得重复震动或连续导航。
- 动画期间主线程无明显卡顿，纸角跟手没有持续跳帧。

建议至少覆盖：

| 平台 | 设备类型 | 重点 |
|---|---|---|
| iOS | 小屏旧机 | 手势距离、文字区纵向滚动、振动是否生效 |
| iOS | 当前主流机 | 双阶段触觉是否过密、680ms 是否自然 |
| Android | 中低端机 | `touchmove -> setData` 跟手帧率、阴影与 3D 变换性能 |
| Android | 高刷新率机 | 快速轻扫速度阈值、动画是否显慢 |
| 鸿蒙微信版 | 可用设备 | `vibrateShort` 和触摸事件兼容性 |

## 6. 建议调参顺序

1. 先固定 `drag-max-angle=5` 和触觉设置，只调 `swipe-distance`，解决误触或难触发。
2. 再调 `flick-velocity`，只处理短促轻扫，不影响慢拖阈值。
3. 然后调 `turn-duration`，确定视觉重量。
4. 最后决定是否保留 `settle-haptic`；不要用触觉掩盖手势识别问题。

每轮只改一个参数并至少完成 30 次操作，避免凭单次主观感受同时改动多个阈值。
