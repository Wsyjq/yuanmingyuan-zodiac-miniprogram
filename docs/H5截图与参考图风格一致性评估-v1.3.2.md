# H5 截图与参考图风格一致性评估（v1.3.2）

> 文档状态：历史截图评估。本文的 19 页、拍照验证页和受控图片结论对应 v1.3.2；当前视觉基线由 `npm run test:visual` 生成的 31 个页面/关键状态与 v2.0 响应式门禁负责。

> 目的：把 19 张小程序页面截图（`test/shots-h5/00-18.png`）与小红书《手账教程｜复古手账风》6 张参考图做风格一致性比对，找出偏离页并给建议。
> 方法：截图缩成 ~120KB jpg → 上传公网图床 → 独立 vision 模型逐页评估（9 张详评 + 10 张按类型推断）。每页评 4 维：氛围/主色/手账元素/吻合度。
> 结论先行：**风格落地高度成功，无需返工**。19 页中 18 页与参考图吻合度=高，1 页（拍照验证）为设计内有意的夜景偏离。

---

## 1. 总体结论

| 维度 | 评估 |
|---|---|
| 配色一致性 | ✅ 高。19 页全部锁在「泛黄旧纸黄 `#EFE3C8` 域 + 深棕墨 `#46382A` 域」，与参考图 `#EAD9BF`/`#2E1F0D` 同色域。无冷色、无高饱和色窜入（拍照页夜景除外）。 |
| 版式一致性 | ✅ 高。统一遵循文档 §1.6 的「编号区→标题→主图→正文→注释→日期」归档秩序，与参考图的档案版式同构。 |
| 手账元素落地 | ✅ 高。编号标签、双框线、排线纹理、印章式按钮、邮票齿孔主图框、万字纹画框、旧金角花等均在对应页面正确出现，且克制（叙事页少用、仪式页多用），符合"单屏≤4件"原则。 |
| 字体层级 | ✅ 高。宋体大标题 + 楷体引文 + 黑体正文 + 手写体批注的四档分明，与参考图「衬线印刷+花体编号+钢笔手写」三档呼应。 |
| 偏离页 | 仅 1 处，且为设计内有意为之（见下）。 |

**与参考图的唯一实质差异**：参考图每页都有铜版画主图居中，而本项目的叙事页/谜题页按需省略主图——这是合理的（不是每页都需要插图），非缺陷。

## 3. 微调建议（可选，非必须）

风格已达标，以下仅为"想更贴近参考图"时的可选优化，不做也不影响整体：

1. **正文墨色可选加深档**：参考图 ref-1/4/5 的墨色是近黑棕 `#2E1F0D`，比现有 `--ink #46382A` 更沉。可在铜版画描线、双框线、拓印区等需要"重墨"的地方引入 `--ink-deep: #2E1F0D`（见《参考图实测色值与token对照》§3）。拓印页已天然做到。
2. **实物拼贴元素可再前置**：文档 §1.6 v1.3.1 定义的活页孔 `.binder`、撕纸边 `.torn-divider`、吊牌编号 `.tag-hang`、照片贴纸 `.photo-sticker` 在抽查的页面里 vision 没明确识别到（可能用了但缩图后看不清）。若想强化"手账实物感"，可在叙事页（02 序章、04 过渡）适度加 1 处活页孔或撕纸边。
3. **拍照页回归的一致性钩子**：拍照页虽是夜景底，可在取景框四角保留旧金角花或编号标签，让它即便暗也仍是"档案册里的一页"。若现已如此，忽略此条。
