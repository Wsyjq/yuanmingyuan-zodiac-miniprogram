# 考察簿与实地导引 UI 增量（2026-09-25）

保留现有 cream/green 配色、字体和正文排版。开发目录当前分支为 feat/game-module-v3，未切换或修改 main 分支指针。

- 右上角考察簿直接进入已遇见史料目录；音频、作品、重新考察等原入口收在“音频、作品与考察设置”。
- 正文按页的 glossary 标注分词，高亮关键词可打开对应史料，不改写原文。无对应字面的标注仍保留正文下方入口。
- 史料复用现有图像、图注和原文；概览、深入、延伸对应原有层级。按用户后续反馈修正：已遇见卡片点开即完整连续展示全部层级及配图，不再受答题状态截断。层级按钮只负责滚动定位，不隐藏其他正文；未来未遇见卡片仍不可打开。
- 右下角导引按钮可拖动，限制在可见窗口范围内；拖动不会误触打开。导引区分考察记录和实际 GPS，八站支持已解锁回看，当前站继续恢复点。
- 定位仅主动点击时调用 host/navigation.js，不持久保存坐标；拒绝或不可用时可重试，不阻断考察。宿主须合并 app.json 中 scope.userLocation 描述与 requiredPrivateInfos，并满足微信位置接口及隐私配置要求。
- 尚无核实的站点坐标：当前只提供本人位置地图和有序考察清单，不画推测路线、不提供距离或精确导航。上线前需补齐现场核对坐标及真机测试。
