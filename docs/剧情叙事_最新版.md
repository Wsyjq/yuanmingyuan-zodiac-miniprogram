# 第廿一图_采风修订版玩法

---

整体故事和玩法：一位博物馆研究助理听到民间传言有第二十一幅铜版画，于是好奇去去一探究竟，他在入口处收到一个信封，里面告诉它循着这个路线走下去，你会知道答案的。当他把所有的谜题解完之后，他发现每个谜题弹出的卡片角落的数字连起来就是今天的日期。

但最后发现：第二十一幅铜版画并不存在，它不是一件失落的文物，而是一种由后来者共同完成的文化记忆。

前二十幅铜版画记录的是：“圆明园最辉煌的时候，它是什么样。”而玩家绘制的“第二十一幅”记录的是：“圆明园经历毁灭之后，今天如何被重新看见。”

当一个文化遗产只剩残骸时，人们如何通过观察、理解和记录，让它重新拥有生命。



由于西洋楼遗址中现场可观察到的遗存较少，大多数文化都隐藏在已被劫掠的文物中，需要通过想象或者搜寻当时的盛况才能更好的理解背后的文化内涵，而这部分内容并不适合在线下实景中设计，让玩家在烈日炎炎中原地站着看视频或者图片这些不在圆明园也能看到的东西对用户的体验并不好。因此我计划在实景游玩版本开发完之后，开发一个脱离实景游玩版本，其形式可以类似于互动影游➕解谜游戏，解密的难度适当提高，可以相互补充，也可以单独使用。



需要的资源

1. 每个点位高清实拍图和稿图
2. 花纹的高清图
3. 每个点位处**可以现场观察到的**遗址背后的文化元素内容
4. 文化解读的审核



小程序设计需求：

> 引用部分的内容可以做成一张张的知识卡片

实景识别或许yolo会好一点，但如果时间不够或者效果不好的话就先调用API吧，但是会慢很多，理论上做个小模型会好些

## 序章

我在博物馆做了两年研究助理，日常都是在整理馆藏图像档案。一天下午，我在整理一批清代铜版画的数字化记录，翻到《西洋楼铜版图》二十幅的条目。

《西洋楼铜板图》于乾隆四十六年至五十一年（1781–1786），由宫廷画家伊兰泰起稿、造办处刻印，贺清泰、潘廷璋等参与，记录了圆明园西洋楼建成时的全貌。这是常识，所有图录都这么写。

但有一份民国年间的著录卡片，在"第二十图"后面用铅笔补了一行小字："闻有第二十一图，未见。"字迹潦草，像是随手记下的传闻。也有人提到"民间盛传铜版画不止二十幅"，但注明"无从证实"。

再往后查，零星还有几处类似的记载。说法各异——有人说它被藏起来了，有人说它根本没画完，有人说它早就毁了，和西洋楼一起烧成了灰。没有一份能给出实证。传闻在学术档案的缝隙里反复出现，像一根刺，拔不掉，也按不平。

我继续翻阅那份残缺的档案，在附件夹中发现了一份尚未整理完成的考察资料。

里面有一封信、一张手绘路线图、几张空白记录页，以及几件用于现场记录的工具。

## 第四站：雨果雕像

雨果雕像——一尊青铜半身像立于花岗岩底座之上，含基座总高约两米（青铜像高约84厘米）。维克多·雨果的面容在树荫下沉静，眉头微蹙，目光投向远方的大水法残柱。雕像在草地上投下一道长长的影子。

底座上刻着中法文铭文。我走近了，逐句读下去："希腊有巴特农神庙，埃及有金字塔，罗马有斗兽场，巴黎有圣母院，而东方有圆明园……有一天，两个强盗闯进了圆明园，一个洗劫，一个放火。"

两个强盗。1861年，雨果写下这封信给巴特勒上尉。他这辈子没来过中国。他写的关于圆明园的一切，都是从掠夺品清单、随军画家的速写、欧洲报纸的炫耀文章里拼凑出来的。但他想象出来的圆明园，比联军亲眼看到的还接近真相。

> 2010年，这尊雕像落成，法国雕塑家娜什拉·凯努女士无偿创作，中法两方代表共同揭幕，作为中法文化交流的纪念。雨果信中的话，被刻在了他凝视的废墟旁边。
