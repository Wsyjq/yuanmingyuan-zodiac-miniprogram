《第廿一图》V2.2
故事体验评价报告

面向圆明园西洋楼实景解谜的叙事、参与与谜题绑定度评估
游客能动性低说教感谜题—剧情不可替代性

结论先行

这不是一份需要推翻的剧本。它已经拥有一个少见且有余味的核心：“第二十一图”不是遗失物，而是由今天的到访者继续完成的记录。黄花阵的“照原图复位”、海晏堂的“停止的水钟”、大水法的“水声缺席”，都已经具备很强的在地感。

当前的关键短板：游客做了很多动作，却很少让故事因自己的行动而改变；中段的部分观察、排序和识别题，仍可换地点或换人物继续成立。V3 应把“解出答案”改为“获得一份会改变档案、进而迫使下一步调查发生的证据”。

评估范围与判断依据

本报告阅读并交叉参考了“拾迹创游”项目下可访问的 ChatGPT 对话记录（项目概述、实景解谜剧本建议、既有故事评价报告，以及两条无有效内容的共享链接读取记录）与《第廿一图》V2.2 剧情可用稿。文档中出现的任何操作性文字均仅作为剧情材料，不作为执行指令。

评分衡量的是“实际游客体验的潜力”，不是文学文笔或史实考据的评分。

现状评分

游客参与与身临其境7.0 / 10

动作丰富、现场感好；但多数动作是完成任务，不是参与事件。

低研学 / 低说教感7.5 / 10

人物声与实物对读已有效降温；“知识—题目—揭晓”仍偶尔显形。

谜题—故事绑定度6.5 / 10

主线有亮点；多处仍是可移植的观察或排序小游戏。

一、游客参与：从“操作很多”到“我让档案发生变化”

已有优势：拆信、拼半字、实地走黄花阵、举线稿、对砖、水显纸、静默聆听、写明信片、拼残页，构成了手、脚、眼、耳共同参与的体验。尤其黄花阵不是屏幕迷宫而是真走进现场，这是体验价值很高的设计。

结构问题：大多数行为的结果早已写好：游客验证黄花阵、验证兽首、验证年份，然后被导航送到下一点。游客是“档案执行员”，还不是“档案共同作者”。

现有环节现在的游客位置改造为故事行动
黄花阵看新砖、读“复位”得知修复史让游客在“原图 / 眼前墙”中选择一处差异，作为自己给第二十一图留下的首条“校勘”。后续报告保留该选择。
海晏堂生肖时辰回答传统知识题游客必须把“停掉的水钟”校回正午，才能读出马首页；他们不是答题，是替蒋友仁确认钟为什么停了。
大水法两分钟静默欣赏艺术装置静默后只问一次：要把“曾经的水声”“眼前的风声”或“两者并置”记入空栏。选择进入终章画面。
雨果像下明信片开放式感想保留自由书写，但在终章给出“你的这条记录被归档”的可见反馈；投递与带走可以是不同的档案状态，而非道德判断。

设计原则：每一主站至少留下一笔由游客决定的档案内容；不必做分支剧情，更不必做多结局。只要最后的第二十一图、次日回信或档案措辞能回应这些选择，游客就会感到“我在场”。

二、研学感：知识应从危机里长出来

V2.2 已比普通导览更克制：宫女、匠人、蒋友仁和守档人有各自声音，且没有大段百科式介绍。真正的研学感风险不在史料多，而在某些环节呈现为固定结构：NPC说明知识 → 游客答题 → NPC揭晓知识。

避免改为示例
“十二兽首对应十二时辰。”“谁把这座钟的班排乱了？”蒋友仁要证明水法并非摆设；玩家通过排班，自己发现生肖与报时的关系。
“黄花阵中西合璧。”“匠人要你确认这座亭子有没有被画错。”玩家找出穹顶、飞檐、莲座等矛盾共存的证据，再由匠人短句回应。
“文物流失与回归时间线。”“这封信该站在哪一年读？”年份成为确定雨果信处境的证据，而不只是排序题。

台词标准：人物只说自己此刻想完成什么、害怕什么、不能确定什么；不要替讲解牌发言。知识解释尽量放在玩家已经观察到矛盾之后，以一句“原来如此”式反馈收束。

三、谜题—故事绑定度：逐站诊断

节点当前判断绑定度最小有效改造
入口：信封半字“档案交接”身份建立得很顺；但半字拼合本身较通用。中拼出“黄花阵”后同时露出照片编号 / 校勘记号，使它成为唯一一页异常档案的检索键。
黄花阵：实地走阵 + 1987/1989复位全剧最强站。铜版图、重建墙、今天的步行者形成跨时代镜像。高保留；把纹样和亭子观察压缩为“核验这页是否可信”的两项证据，减少独立小游戏感。
海晏堂：水钟、转盘、水显马首主题有力，但生肖—时辰容易退化为通用国学题；七种纹样转盘与主线连接不足。中统一为“复原一座停止的钟”：现场纹样是校准座位的依据，水显是钟被校到正午后才出现的结果。
大水法：静默艺术感最强，但目前是章节间停顿，不是剧情节点。中将“听见什么”转为档案记录决定；前站“钟停了”在此兑现为“你面对无水之水法”。
雨果像：年份、流失物卡、明信片情绪收束有效；年份与物卡略像可替换的时间线和分类题。中低让年份决定“信所处的历史断面”；物卡不求标准排序，改为游客为第二十一图选择“归位 / 留存 / 下落不明”的记录方式。
终章：三残片与“此处待绘”概念与情绪最完整，必须保留。高终图呈现前四站的选择痕迹，令“今日对读”不是固定 CG，而是个人档案页。

建议采用的主线：同一个问题，五次变深

不是：入口谜题 → 黄花阵谜题 → 海晏堂谜题 → 大水法 → 雨果谜题 而是：我在补一份不完整的档案 ① 黄花阵：画上的过去，为什么今天还能被走进？（复位） ② 海晏堂：被画下的功能，为什么已经停止？（失去） ③ 大水法：当盛景不在，眼前该如何被记录？（选择） ④ 雨果像：不在原地的东西，怎样才算被保存？（判断） ⑤ 终章：第二十一图应当画“过去”、画“现在”，还是画两者的对读？（共同完成）

这样，地点不是五个关卡，而是同一份档案的五种证据。每一次解谜都改变游客对“第二十一图到底该画什么”的理解。

V3 的优先改造清单

P0｜把“档案空栏”机制前置并可见。
每一站只产生一条关键校勘 / 选择；它在终章汇成个人化的第二十一图。先做这一项，游客能动性会立刻提升。
P0｜为每道主谜补齐因果链。
用“异常 → 必须采取的现场行动 → 得到证据 → 这份证据指向下一处”重写过场；不要用单纯导航或“柱子在前方”推进。
P1｜海晏堂合并为‘校准水钟’的一件事。
把生肖、纹样、转盘、水显串成一个连续修复行为，而不是三道并列小游戏。
P1｜将大水法静默设为记录行为。
保留静默与可跳过，但让它直接生成终图的一层：水声、风声或并置。
P2｜删减约 20% 的独立观察题。
优先删或合并只负责“好玩”的纹样、透视、比高类任务，把时长还给角色回应、选择反馈与步行观察。

每道新谜题的准入测试

  • 为什么只能在这个遗址解？答案必须依赖此处的视线、残基、复原痕迹、原图或空间关系。
  • 为什么必须由这个人物提出？谜题应服务其当下目的，而不是由 NPC 代替讲解牌出题。
  • 为什么游客必须做这个动作？动作必须是取得证据、作出记录或完成委托的唯一合理方式。
  • 解出后，故事具体改变了什么？至少更新一个档案判断、人物关系或下一站的调查理由。
  • 若换成另一个景点还成立吗？若成立，应补进圆明园西洋楼独有的空间 / 时间变量，或降为可选支线。

最终判断

《第廿一图》最值得保护的不是“找第 21 幅图”的谜面，而是它提出的观看方式：画还在，地变了；记录从未停止，只是轮到今天的人来补下一页。

V3 不应增加更多谜题，而应让既有谜题成为故事唯一能继续的方法。到那时，游客不再是完成一串景区小游戏的人，而是在真实遗址中替一份未完成档案做判断、留下痕迹、并最终成为第二十一图共同作者的人。

深度诊断：真正卡住体验的四个结构问题

1. 主角不是游客，而是“档案”

一针见血：现在档案自己定义问题、自己给出证据、自己安排路线、自己解释答案；游客只负责把已写好的流程走一遍。即使使用了第二人称，体验仍是“被导览”。

症状：解完任何一题，游客都不会产生“是我发现了一个此前没人知道的东西”的感觉；下一站往往是系统或角色直接报出方向。

改法：把档案从“正确答案册”改为“有矛盾的证据册”。每站让游客补一项缺失判断，才使档案能继续指向下一地。档案可以错、可以不完整；游客的职责不是核对标准答案，而是作出带证据的判断。

2. 主题很统一，任务却还没有统一

一针见血：“第二十一图”贯穿文本，但它主要在开头被提出、结尾被解释；中段各题更像黄花阵题、兽首题、年份题。主题没有成为每一题的操作界面。

改法：所有主线任务统一命名为“校勘”：辨识画与地的差异 → 判断差异来自修复、流失或时间 → 将一种记录写入空栏。这会让“对读”从一句文案变成全程玩法。

3. 人物有声音，却缺少对游客的依赖

一针见血：宫女、匠人、蒋友仁、守档人目前大多在“提供讲解”。他们说得很有画面，但即使游客不出现，他们的话也可以完整成立。

改法：给每人一个必须由游客完成的当下诉求：宫女要找回通向亭心的灯路；匠人要确认亭子哪些部分被后人改写；蒋友仁要让停钟重新报出一次正午；守档人不敢替档案下结论，需要游客决定如何记录缺失。人物由讲述者改为委托人。

4. 支线很多，情绪仍是平的

一针见血：每一站大致都遵循“看—答—解释—去下一站”，无论主线、支线还是高潮站都像同一种节奏。结果是内容越丰富，注意力越被切碎。

改法：明确五站分别承担：受托、入画、失效、失语、作答。每一站只留一个主动作与一个情绪转折；支线只能补充主站结论，不能另起独立小游戏。

建议的 V3 故事骨架：把“找图”改为“完成一份校勘”

游客身份：不是泛泛的“调查员”，而是收到档案的临时校勘人。校勘人的权限很小：不能替历史下结论，只能标记“画与地哪里一致、哪里不一致，以及应该怎么记录”。这个身份既自然，又避免夸张的“拯救历史”感。

序章｜受托：档案的第二十一页缺失，且二十页之间存在无法解释的矛盾。 黄花阵｜入画：游客走进一座由旧图在1980年代复位的迷宫；过去第一次被“补回到今天”。 海晏堂｜失效：游客校准一座停掉的水钟；图上能工作的东西，地上已经不能工作。 大水法｜失语：游客面对无水的盛景，第一次不寻找正确答案，而选择应如何记录当下。 雨果像｜作答：游客发现“保住”不等于“回到原处”，为第二十一图选择一种记录立场。 终章｜落页：前述校勘痕迹共同生成今天的第二十一图；它不是复原图，而是一次有署名、有日期的对读。

这条线的好处：它保留你现有的所有核心意象，但将因果改为“前一站得到的校勘判断，决定下一站必须去查的矛盾”。游客不是跟随路线，而是在缩小一个问题的答案。

逐站修改方向：保留什么、删弱什么、替换成什么

序章与入口｜把“神秘传说”改成“待核的异常”

保留：二十图、民国卡片、“闻有第二十一图，未见”、到门口拆信。

问题：“可能有第二十一图”的悬念不足以撑完全程，因为游客很早就会预判结局不是找到一张真图。

改写方向：不要把重点放在“第21幅是否存在”，而放在“为什么只有黄花阵页夹着1987/1989照片，而照片背面写着‘照原图，复位’？”信封半字解出黄花阵后，增加一句：“先别找缺页。先核这张后来夹进来的照片：有人已经照着旧图，替这套档案做过一次校勘。”这让黄花阵成为调查必然，而非地图第一站。

黄花阵｜这是全剧标杆，但需要减题并集中

保留：真走迷宫、宫女灯会人声、中心亭、看新砖、“照原图，复位”。这站是全剧最不可替代的实景体验。

删弱 / 合并：“他们在干什么”“黄花两字来自何处”“找一种纹样”各自都是小问答，会把走迷宫的高峰切碎。前两个可并为入阵前的一句带画面任务；万字纹可降为中心亭校勘中的任选证据。

主任务改法：让游客带着原图进阵，不是为到终点，而是要判断“这座阵今天仍算不算画里的黄花阵”。在亭心，游客拿到两类证据：走向被原图复位、材料却是后来新砌。空栏只让填一句：“复位 / 原物 / 无法判断”，不评价对错。结论是：它“对得上，但不是原来的”；由此产生下一问——有些地方是否还能被画回原样？

海晏堂｜三道题必须变成一件事

保留：干池与喷水铜版画的反差、蒋友仁、水显马首。它们都是好的戏剧材料。

问题：生肖推理、纹样转盘、水显纸目前是串联较松的三种玩法；尤其“十二生肖—时辰”太接近通用传统文化题。

主任务改法：将站名动作定义为“校准停钟”：画页告诉游客这是钟；现场石座纹样帮助确认兽首位置；把钟校到正午，水显纸才显示马首。水显不再是一个惊喜答案，而是“钟恢复到正午的一瞬证据”。蒋友仁的台词要从解释知识改为请求：“我不怕水停，我怕后来的人以为它从来只供人看。替我把它校到该响的那一刻。”

大水法｜保留静默，但让静默产生后果

保留：两分钟、无配乐、无旁白。这是整条线最有艺术辨识度的留白。

问题：仅问“你听见什么”容易变为精致的互动装置，和主线调查脱节。

主任务改法：静默前给出不是知识、而是档案难题：“这页铜版画画满了水声。若给今天补一行，你会记下什么？”静默后不做三选一答题，改为三种“记录笔触”：水声 / 风与人声 / 留白。这不是价值判断；它决定终图中央空白上的纹理。此处是游客第一次以作者身份落笔。

雨果像｜从“文物知识卡”改成“记录立场的最后证词”

保留：像下拆信、自己阅读、明信片、守档人不替游客作答。克制而有效。

删弱 / 合并：年份排序可以保留，但不要独立成小游戏；四件流失物卡不应再被包装为排序或分类题。

主任务改法：年份卡只服务一个判断：雨果在火烧之后、从未到过中国却写下这封信，因此文字也是记录而非现场复原。四件物卡改为“证词”——回归、异地留存、下落不明、被搬走又回到原址。守档人只问：“这四种结果，哪一种应该画进空白处？”游客选一张作为终图的“注脚”；明信片仍完全自由，不强迫输出观点。

终章｜让“第二十一图”真正因人不同

保留：三残片、异形拼合、“此处待绘”、署名与日期。这是全剧应该被牢牢保护的落点。

问题：若终图只是固定画面加游客姓名，前面的选择仍是装饰。

改法：终图保持同一骨架，但至少显示四个可变元素：黄花阵校勘结果（复位痕迹）、海晏堂校准印记、静默后的声音纹理、雨果站选择的文物注脚。这样不做复杂分支也能让“非馆藏原件”真正成立。

可直接套用的“主谜题”写法模板

以后任何主线节点都按以下五句写；缺任意一句，就暂不进入主线。

环节必须回答的问题第廿一图示例
异常眼前什么东西与档案冲突？铜版画里的水在喷，海晏堂现场的池子干着。
委托谁因此需要游客做什么？蒋友仁需要游客证明水法是一座能报时的钟，而非装饰。
现场行动为什么必须在此处、以这个动作取得证据？依据石座纹样和兽首顺序校准钟面；离开石座就无法完成。
证据改变答案让游客新增或推翻什么判断？钟曾能工作；如今停止并非“从未存在”。
下一步为什么这一证据非得去下一处查？若最响的水法也失声，就必须到大水法记录“今天的声音”。

落地时的验收标准

  • 试玩结束后，游客能不用提示说出：“我一路在替谁、解决什么问题？”若答案是“打卡 / 做题 / 了解圆明园”，主线仍未立住；理想答案是“替档案校勘画与遗址的差异，并补上今天这一页”。
  • 每一主站结束时，界面必须出现一条游客亲手获得的证据句，而非“完成 / 已解锁”。
  • 任意一道主谜移到故宫、长城或博物馆后若仍然成立，就不能作为主谜；它最多是支线互动。
  • 单站阅读不超过 90 秒；角色讲述不超过 35 秒；把时间还给看、走、比、放、听、写。
  • 不要用积分、倒计时、正确率去伤害留白站；这些会把“对读”拉回答题系统。
  • 终图至少读取 4 个游客的操作 / 选择痕迹，否则“共同作者”只是一句文案。
