# 门票制付费 · 对接园方已有支付工程（宿主对接版）

> 版本：v1（2026-09-18，随 Host Adapter 契约 v1.4.0，worktree feat/v22-board-merge）
> 模式拍板：整体买票制，门页（gate）在模块最前 cover 之前；园方小程序已有付费工程，全量复用。

## 1. 游客侧链路

```
园方小程序入口 → gate 门页（检票）
                  ├─ 已购（查权益）→ 自动放行 cover，进模块
                  └─ 未购 → 门票卡（内容清单 + 价格 + 「解锁完整考察」）
                             └─ 支付（园方已有工程）→ paid → 放行
```

- 一次解锁，此账号长期有效；退款后权益自动收回（以园方订单状态为准）。
- 深链防绕过：cover 页 onLoad 自查权益，未解锁 redirect 回 gate（全量内页守卫待接入时按需铺开）。

## 2. 宿主要做的两件事（Adapter 内实现，形态对模块透明）

| 契约方法（v1.4.0） | 宿主实现（对接已有付费工程） |
|---|---|
| `requestPayment({sessionId, sku:'plate21_full'})` → `{status:'paid'\|'cancelled'\|'failed'\|'unavailable', orderId?, entitlementId?}` | **形态A 接口级**：Adapter 内调已有统单接口 → 拿支付参数 → `wx.requestPayment`；**形态B 页面级**：跳已有收银台页，回来后查单确认。支付回调落权益库 |
| `checkEntitlement({sessionId})` → `{unlocked, entitlementId?, unlockedAt?}` | 按当前用户（openid）查订单/权益表；退款即 unlocked=false |

- 金额/商品全部在园方商品库维护，模块前端零金额逻辑；门页价格文案由商品配置下发（现为演示占位 `¥ 19.9`）。
- `unavailable`（未开通付费 / iOS 虚拟支付差异）：门页自动隐藏购买入口，显示「暂未开放」——不出现死按钮。

## 3. 权益判定口径（鉴权边界）

- **权威在园方服务端订单**：gate 放行与 cover 守卫每次可查 `checkEntitlement`；
  本地 `flags.premiumUnlockedAt` 仅是缓存（已解锁用户命中缓存不受接口抖动影响）。
- 支付结果以服务端回调为准，前端返回值只做 UI 引导。
- 换设备恢复购买 / 退款收回，都由服务端查询自然解决，模块不维护账。

## 4. 需与园方确认的清单

1. 付费工程对外是**接口**还是**收银台页面**（决定 Adapter 形态 A/B，模块无感）
2. 商品建档：SKU `plate21_full`、名称「西洋楼铜版图·第二十一图 完整考察」、定价与调价机制
3. 订单/权益查询接口：按 openid 查是否有效购买（含退款状态）
4. iOS 处理方式：园方现有付费在 iOS 的做法；若虚拟内容受限，iOS 端走 `unavailable` 隐藏入口或线下渠道
5. 客服与退款流程归属（园方既有渠道）；对账字段（orderId/entitlementId 回传）
6. 分成/结算模式：建议授权费（买断/年费）+ 可选流水分成，资金流全部走园方账户

## 5. 内容防护边界（产品决策）

- 当前：门票制 + 内容随包分发（voice-a..j 音频分包）。防正常路径进入，**不防翻包**——文旅低客单价场景通常可接受（"防君子"级别）。
- 若要求未付费设备上无内容：付费音频改 CDN 按权益下发临时链接（园方 CDN 鉴权），随包仅保留免费试听段。此项改变接入清单（+CDN 鉴权），需提前与园方谈。

## 6. 联调验收（建议 CT-16）

1. 未购 → gate 显示门票卡，点解锁 → 园方收银台 → 支付成功 → 放行 cover；杀进程重进直接放行（缓存命中）
2. 已购换设备 → 冷启动查 `checkEntitlement` → 放行（恢复购买）
3. 退款后 → 下次进入被拦回 gate（权益收回）
4. 宿主返回 unavailable → 购买入口隐藏，无死按钮
5. 深链直达 cover（未购）→ redirect 回 gate
6. 埋点：`purchase_initiated` / `purchase_completed` 上报

## 7. 本地演示说明

local-adapter 为演示实现了模拟支付：`requestPayment` 直接返回 `paid` 并在 storage envelope 落
`flags.premiumEntitlement`（模拟宿主权益库），`checkEntitlement` 据此返回——开发者工具里可走通
「门票卡 → 解锁 → 检票 → cover」全流程；清缓存即回到未购状态。测试 `test/gate.test.js` 7 项守门。
