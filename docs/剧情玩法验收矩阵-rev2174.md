## 1. 状态定义

| 状态 | 含义 |
|---|---|
| `DONE` | 当前工程已有真实交互、状态落库、成功/失败路径和自动化覆盖 |
| `IN_PROGRESS` | 已进入本轮实现，尚未完成全部验收 |
| `EXTERNAL` | 程序入口可实现，但被实体物料、内容或宿主服务阻断 |
| `HOLD` | 产品或授权证据未冻结，不得作为正式版本放行 |

## 3. 已冻结的产品决策

1. 信封、七纹样转盘和水显纸使用真实实体道具；小程序只做操作说明、结果确认和进度记录。
2. 四图观察必须记录玩家真实拍摄结果；最低交付不要求 AI 场景识别，也不得用恒通过或两次后放行冒充识别。
3. 黄花阵名字由来保留文字输入，并补充语音入口；语音转写与文字统一进入同一个语义校验服务。
4. 语音、相机和相册权限必须在使用时请求，拒绝权限后给出明确恢复路径，不能让主流程无提示卡死。
5. 所有正式图片、视频和字体必须通过 `npm run check:commercial`；`hold` 资源不能进入商业发布版本。
6. 实体信封、七纹样转盘和水显纸已具备；本轮不再将物料制作列为软件阻断项。
7. 万字纹寓意与路线线索分离：前者仅为“福寿绵长”，后者由手绘路线图承担。
8. 玩家照片唯一成果源为 `snapshot.flags.s2PhotoRecord`；参考图不得进入报告或手册照片槽。

- 四槽完成后生成四图考察卡，再展示“西学东渐后的皇家审美转译”史料卡并收集日期数字。

## 5. 本轮不伪实现的外部缺口

| 缺口 | 当前处理 |
|---|---|
| 语音转写与语义 API | 保持 `EXTERNAL`，接口、隐私和验收语料确认后再写生产实现 |
| 海晏堂与结尾视频 | 只保留失败可继续的媒体骨架，不生成无授权占位冒充正式素材 |
| 全局第 N 版 | 保持 Adapter 契约，不用本机计数冒充全局序号 |
| AI 与书格图片授权 | 保持商业闸门失败，证据完整或替换素材后再改为 `approved` |

## 6. 完整版本门禁

```powershell
npm test
node test/harness/render.js
node test/check-font.js

```
