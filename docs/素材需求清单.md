## 交付约定

1. 所有切图类素材同时交付**源文件**（PSD/AI，分层）与**导出件**（webp/png）。
2. 标注"含坐标表"的素材，交付一份 JSON：热区/空位/点位的 `x, y, w, h`（以交付图像素为基准）。
3. 命名即编号。存放分两路：**图标与小纹理**放入分包 `plate21/module/assets/`（icon/纹理类）；**大图与视频**（IMG-P/S/F/V 系列、IMG-M01、VID-E01、配乐）上传 CDN，按《宿主接入方案.md》manifest 中的 `cdnDomains` 目录组织——微信单分包上限 2MB，分包内素材预算须控制在 500KB 以内。
4. 占位期程序以灰底 + 编号文字占位图开发，素材就位后无代码改动替换。
