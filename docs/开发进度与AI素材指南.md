## 二、AI 素材生成指南

### 模型与调用

- 文生图：`doubao-seedream-5-0-260128`，接口 `POST /v1/images/generations`
- 图编辑：`Qwen-Image-Edit-2509`，接口 `POST /v1/images/edits`
- 视频：`doubao-seedance-2-0-260128`
- **尺寸下限 3,686,400 像素**：竖图 `1920x2560`，横图 `2560x1920`，方图 `1920x1920`（或更大）
- 本地调用：`GPN_KEY=<key> node test/gen-image.js "<提示词>" <输出.png> <尺寸>`
- 生成后处理：jimp 缩放到设计尺寸转 jpg/webp（q80~85），存入 `plate21/module/assets/img/`

### 风格总纲（所有图共用）

**通用模板**：

```
18世纪欧洲铜版画蚀刻风格插画：<主体描述>，密集交叉排线构成明暗，
单色暖褐墨线稿，印在米白微泛黄旧纸上，边缘锐利，古典制图学精确感，
<构图要求>，无文字无水印无彩色
```

**六条铁律**：
1. 风格锚定词不可少：「18世纪欧洲铜版画蚀刻」「密集交叉排线」「单色暖褐墨」
2. 一律要求「无文字」——任何要出现在画面里的汉字都后期叠加（AI 长文不可靠）
3. 一律「无彩色」；唯一例外是 IMG-S2B 允许「极淡暖黄」点缀灯笼
4. 题材要庄重：圆明园遗址题材，禁止卡通化、艳丽化、游戏感
5. 同一素材多帧/多件时，用同一提示词只改主体句，保证风格一致
6. 生成失败或出现文字/水印/彩色，重roll，不凑合
