## 三、关键设计决策与解法（wiki 只写了问题，没写这些修法）

### 3.1 NPC 改造方案（wiki 方向A 完全没记录）

- 现状问题确认（00:15:57）："研究助理的事，你要么就给他定义为现代人……这个人一直是旁白，有的时候老会跳出来。"
- 修法（00:22:19–00:23:12）：把**神秘档案的主人设定为"长期研究第21幅图的人"**。一开始玩家不知道他是谁，一路上通过信件、字迹、不断传递的信息元素铺垫；后面发现"他不是再找一张画，而是说谁愿意替这个时代去留下今天圆明园的一个东西"——最后游客才意识到**被选中的是自己**。
- 设计意图："游客要与这一个人去建立某种联系。"

### 3.2 第21幅图的立意深度（wiki 只当"收尾机械"问题）

- 00:13:51–00:15:32：第21张图是"游客自己去找到当今时代的第21张图"，它"缺的不是建筑，而是观点的深度"。
- 层次链（第21图应有的信息层级）：游戏里的生活 → 中西文化 → 清王朝的翻译/转化 → 技术、权力和时间 → 毁灭之后不同文明怎么评价（雨果）→ 现在的人怎么看。

### 3.3 分层落地的四条决策（wiki 方向C 只有三层示例）

1. **音频主线不分层**（00:54:28）："音频这个事不存在小孩大人谁之分，只有问题的难度上存在。"
2. **亲子靠分工不靠降难度**（01:09:43）："小朋友是你主要去看，家长帮你去记录，家长会有一个引导的作用……不同的人群有不同的分工，大家会自己玩出不同的玩法。"
3. **王浩冉的两难（会议真实难点）**（00:42:03–00:43:41）：加大谜题难度 → 像密室（他亲测中国典籍博物馆时间解密游戏："文化的承载属性并不是很多……更像一种密室"）；提文化厚度 → 说教感（"他们可能就是来玩的"）。此两难 wiki 未记录，后续讨论的解法见下条。
4. **散落在各处的解法线索**：
   - 判断邀请句式（00:46:44）："变成一种自然的发现者……我发现了一个奇怪的地方，你帮我判断一下。"
   - 生疑代替出题（01:23:28）："有些东西根本就不需要说谜题……我们做一些东西是要让他有问题可问。他问问题不害怕，也不一定这个问题必须得我们来解答。"
   - 景德镇双版本模式（01:06:32）："每一个景点后面有一个最基本的讲解，后面有一个复杂一点的、完整版。"并强调"一定要让他可选，现在大家都是我不想跟着你走，我想选"（01:09:05）。
   - **深度主场放回家之后**（01:07:09–01:09:05，王浩冉提案、甲方热烈附和）：线下只对应一个结局，回去之后还有"尾声或者叫回响"。

### 3.4 音频生产原则（wiki 细化区只写了三轨混音）

- **不能文字稿直转音频**（00:49:49）："不是说把文字稿直接去给它配成音频，你中间是需要一些情节化的设计。"注意：01:40:38 桜雨又提了一次"是不是说把现有的文字直接啪用音频一处理"，单看容易被误读成松动，但她紧接着补的是"口语化、剧情化、情绪化……词一定要有引导性、要柔"（01:40:57–01:41:02）——是对 00:49:49 的重申，不是推翻。
- **先给结论再展开**（01:31:07 一带，含裴老师观点）："我可以一上来先跟你讲（结论）……后面听不听不重要"；"音频是有语气、语速的快慢，它是可以控制人的情感的"（01:32:10）。
- **情感化引导词**（01:41:02）："情感化的词一定要有引导性，一定要柔，不要太生硬。"
- **音频引导的范式示例**（00:52:32–00:53:31，可直接当脚本样板）："你刚才看到的是黄花阵，它其实是被设计出来让人迷路的空间。但接下来要看到的都是一套极其精确的系统……它可以控制水、控制时间，甚至让12只动物同时报时。沿着这条路继续走，等你看到一片塌下去的地基，然后停下来。"——音频四职能：给方向、讲知识（不需要太多）、铺剧情、调节奏制造期待。
- **进站前历史音**（01:13:08–01:13:32）：进黄花阵前可先播"嬉戏打闹的声音"等与主题相关的背景音，帮助更快切入。
- **音频与讲解的关系**（00:39:00、00:49:38）："我们的音频里面其实是包含了讲解……它是其实是一套走路中的声音的叙事，自然的涵盖（讲解），不是特别生硬的去表现它。"

### 3.5 序章时长顾虑及解法（wiki 未记录）

- 王浩冉的顾虑（01:16:31）：来龙去脉用音频讲清需要 3–5 分钟，担心"人家都已经快到这个点位了，他还在觉得前面这部分我还没看完"。
- 甲方解法（01:16:53）：参照百度网盘时间线，做**目录/章节跳转**。

### 3.6 开放题的确认（wiki 标了【形式待思考】，实际会上已确认一半）

- 王浩冉问：开放题无法校验、不做任何评判，这种形式 OK 吗（01:33:46）。
- 甲方答（01:34:19–01:36:11）：OK。除纯客观题外，开放性题都不做评价；目的是沉淀观点——"大家就是大家的想法和观念"，用于后续文创、回信引用、甚至邀请有共鸣的玩家参加文化交流活动。

## 七、道具与机制小细节（wiki 方向B 之外的零散补充）

- **道具包命名**（00:24:16）：现在定义成"西洋考察的档案"，甲方倾向直接叫"第21幅图档案包"之类，"后续再斟酌，倒不是要命的事"。
- **观察卡布局**（00:26:13–00:26:18）：透明观察卡**不一定要叠在一起，可以左右布局**（左复原图/右现状图）+ 透着打卡拍照；只做"具有打卡意义的核心几个点，不一定每一个都做"。

- **触觉件**（00:29:32–00:31:41）：建筑纹样压纹纸、铜版凹凸印刷简易版；甲方主动提到"我上次在哪个地方看到过"愿意回头找参考。**小型烫印片目前没有设计**（王浩冉 00:31:09–00:31:16 确认"还没设计"），甲方"回头我也去找一下，我觉得是可以的，不是跑到文物上去拓的"。
- **水写纸隐藏文字**（00:32:17）："水写纸里面隐藏的文字怎么样？"——被点名的候选玩法。
- **信封内的集印逻辑**（00:31:41）：第一站盖黄花阵观察印、铅笔拓纹样等"乱七八糟的东西"。
- **结尾钢印**（00:33:05–00:33:46）：电子盖钢印动画必须配"咔嚓"声；文案形态"第21幅图 第X号 / 第X位纪念者 / 记录者"。

- **现场明信片**（01:35:06 一带）：包里可以放一张明信片让游客写，"寄给谁、自己留收藏都可以"，同时为后台沉淀素材。

## 八、飞书 wiki 文档自身的偏差与空白

1. **「四、行动指南：重构流程」白板基本为空**：仅 5 个节点——"剧情按照情绪线升级优化 → 确定情绪引导主线"、"音频的设计 → 环境背景音设计 / 剧情+讲解配音设计"。所谓重构流程尚未被定义，是团队可主动起草的空位。
2. **时长表述是引申**：原文核心是甲方**推翻自己上次"40–45 分钟到一小时"的预估**（00:12:52）："我觉得不对，我们现在是要让游客去慢下来、静下来。"——是节奏哲学，不是"整体时长拉长"的量化指令。wiki 的"整体游玩时长可以拉长"为记录者推论。
3. **wiki 未记录"多交流/多沟通"的协作预期**（01:39:53、01:42:08）："课程还是在于不断的打磨""隔一段时间咱们就再沟通再交流""你们需要线下来讨论或者怎么样都可以，我们找过去找个地方也都可以。"
4. **逐字稿为 ASR 转写**，存在大量同音错字（见下表）。wiki 总结做了正确转写，但直接引用逐字稿时需先过一遍。
